# Rule: `$` in shell scripts vs Makefiles

**Shell scripts** (`.sh`, `.bash`, `.zsh`): use single `$` for variables.
`$$` means PID (almost never intended).

**Makefiles** (`Makefile`, `*.mk`): use `$$` to pass a literal `$` to the
shell. Single `$` is for Make variables only.

| Context    | Shell `$HOME` | Make var `$(CC)` | Shell PID |
|------------|---------------|------------------|-----------|
| `.sh` file | `$HOME`       | N/A              | `$$`      |
| `Makefile` | `$$HOME`      | `$(CC)`          | `$$$$`    |

Before writing any `$`, check: *am I in a Makefile or a shell script?*
Determine file type from the `<!-- file: -->` marker, not surrounding context.
