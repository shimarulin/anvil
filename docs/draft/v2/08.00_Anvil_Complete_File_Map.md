## Layer → Plugin Mapping

| Layer    | Plugin file       | Anvil modules used                                    |
|----------|-------------------|-------------------------------------------------------|
| Core     | (none)            | Loaded directly in boot sequence                      |
| Lang     | lsp.lua           | `anvil.lang.*` (treesitter, mason, lsp, conform, etc) |
| Editor   | lsp.lua           | `anvil.editor.lsp`, `anvil.editor.treesitter`, etc    |
| Editor   | editor.lua        | `anvil.core.icons`                                    |
| Editor   | navigation.lua    | (standalone)                                          |
| AI       | ai.lua            | `anvil.ai.*`                                          |
| AI       | ai-keys.lua       | `anvil.ai.*`                                          |
| Git      | git.lua           | `anvil.git.*`, `anvil.core.icons`                     |
| Workflow | workflow.lua      | `anvil.workflow.*`, `anvil.lang.tasks()`              |
| UI       | ui.lua            | `anvil.ui.*`, `anvil.core.icons`                      |
| Platform | (none)            | Loaded in boot sequence                               |

## Boot Order

```
init.lua
  └─ anvil.boot()
       ├─ 1. core/env.load()
       ├─ 2. config.apply()
       ├─ 3. core/logger.setup()
       ├─ 4. core/events.setup()
       ├─ 5. core/options.apply()
       ├─ 6. core/autocmds.setup()
       ├─ 7. core/keys.setup()
       ├─ 8. platform.apply()
       ├─ 9. lang.setup()
       ├─ 10. _register_commands()
       └─ 11. events.emit("ready")

  └─ lazy.nvim bootstrap
       └─ plugins/*.lua loaded
            ├─ lsp.lua → editor/lsp.setup() → registers servers
            ├─ editor.lua → standalone plugins
            ├─ navigation.lua → telescope, harpoon, flash
            ├─ ui.lua → theme, statusline, explorer
            ├─ git.lua → gitsigns, diffview, lazygit
            ├─ workflow.lua → overseer, persistence, project
            ├─ ai.lua → codecompanion, minuet, mcp (lazy)
            └─ ai-keys.lua → AI keymaps
```
