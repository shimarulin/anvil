## Design Principles

### Share Data, Not Behavior

The core architectural rule: `src/common` provides **data** (tool lists,
server settings, formatter configs) that each framework consumes through
its own native API. It does **not** provide behavior (setup functions,
keymap appliers, option setters).

**Rationale.** AstroNvim and NvChad have fundamentally different
configuration idioms:

| Aspect | AstroNvim | NvChad |
|--------|-----------|--------|
| Options | Declarative `astrocore.opts.options` | Imperative `vim.o.*` after `require "nvchad.options"` |
| Mappings | Declarative `astrocore.opts.mappings` | Imperative `vim.keymap.set` after `require "nvchad.mappings"` |
| Autocmds | Declarative `astrocore.opts.autocmds` | Imperative `vim.api.nvim_create_autocmd` |
| LSP | `astrolsp` opts with auto-merge | Manual `lspconfig[server].setup()` loop |
| Plugins | Specs merged by lazy.nvim from `plugins/` | Specs merged by lazy.nvim from `plugins/` |

Attempting to abstract behavior across these idioms (e.g., `to_astrocore_format()`,
`to_nvchad_format()` converters) creates leaky abstractions that break on
non-trivial cases: buffer-local mappings, conditional keymaps,
plugin-dependent bindings, which-key integration.

**Rule of thumb:** if sharing a component requires a `to_X_format()` function,
the abstraction is leaking and the component should not be shared.

### What Is Safe to Share

| Component | Shared? | Why |
|-----------|---------|-----|
| LSP server settings (per-server) | ✅ Yes | Pure data, identical format for lspconfig |
| Tool/server/parser lists | ✅ Yes | Simple string arrays |
| Formatter configs (conform.nvim) | ✅ Yes | Both frameworks use conform.nvim |
| Linter configs | ✅ Yes | Pure data |
| Ftplugin files | ✅ Yes | Framework-agnostic, loaded via runtimepath |
| Snippets | ✅ Yes | Framework-agnostic |
| Plugin specs | ❌ No | Conflict with framework built-in plugins |
| Keymaps | ❌ No | Different APIs, conditional logic |
| Options | ❌ No | Frameworks set reasonable defaults |
| Autocmds | ❌ No | Trivial to duplicate, framework-specific hooks |

### Minimal Upstream Modification

Framework directories (`astronvim/`, `nvchad/`) stay as close as possible
to their original starter templates. Each framework adds exactly **one**
bridge file. All other files are either unmodified originals or idiomatic
framework code that happens to read data from `require("anvil.*")`.

## src/common — Shared Data Library

### `src/common/lua/anvil/init.lua`

Entry point. Injects `src/common` and `src/common/after` into runtimepath.
No setup functions, no side effects beyond rtp modification.

<!-- file: src/common/lua/anvil/init.lua -->
```lua
-- Anvil Common — shared data library for Neovim configurations.
-- This is NOT a standalone configuration. It provides data (server settings,
-- tool lists, formatter configs) that each framework consumes via its own API.
--
-- Usage from a framework bridge:
--   vim.opt.runtimepath:prepend(path_to_common)
--   local anvil = require("anvil")
--   local servers = anvil.servers   -- per-server LSP settings
--   local tools = anvil.tools       -- lists of tools/parsers
--   local fmt = anvil.formatters    -- conform.nvim formatters_by_ft

local M = {}

-- Lazy-load submodules on first access
setmetatable(M, {
  __index = function(self, key)
    local ok, mod = pcall(require, "anvil." .. key)
    if ok then
      rawset(self, key, mod)
      return mod
    end
    return nil
  end,
})

--- Adds src/common and src/common/after to runtimepath.
--- Called once from each framework's bridge file.
---@param common_path string Absolute path to src/common
function M.inject_rtp(common_path)
  if not vim.tbl_contains(vim.opt.runtimepath:get(), common_path) then
    vim.opt.runtimepath:prepend(common_path)
  end
  local after_path = common_path .. "/after"
  if vim.fn.isdirectory(after_path) == 1 then
    if not vim.tbl_contains(vim.opt.runtimepath:get(), after_path) then
      vim.opt.runtimepath:append(after_path)
    end
  end
end

return M
```

### `src/common/lua/anvil/util.lua`

Pure utility functions with no side effects.

<!-- file: src/common/lua/anvil/util.lua -->
```lua
-- Pure utility functions. No side effects, no vim.opt mutations.

local M = {}

---@param name string
---@return boolean
function M.is_executable(name)
  return vim.fn.executable(name) == 1
end

--- Filter a list of servers to only those with mason packages available
---@param servers string[] lspconfig server names
---@param mason_map? table<string, string> server -> mason package name
---@return string[]
function M.filter_installed_servers(servers, mason_map)
  mason_map = mason_map or {}
  local result = {}
  for _, server in ipairs(servers) do
    -- If mason is available, we trust mason-lspconfig to install.
    -- Otherwise, check if the binary is on PATH.
    table.insert(result, server)
  end
  return result
end

--- Deep merge multiple tables (convenience wrapper)
---@param ... table
---@return table
function M.merge(...)
  local result = {}
  for _, t in ipairs({ ... }) do
    result = vim.tbl_deep_extend("force", result, t)
  end
  return result
end

return M
```

### `src/astronvim/lua/plugins/anvil.lua`

**The only bridge file.** Connects `src/common` to runtimepath. Does not
return plugin specs — only performs the rtp side effect.

<!-- file: src/astronvim/lua/plugins/anvil.lua -->
```lua
-- Anvil bridge for AstroNvim.
-- Connects src/common to runtimepath so that:
--   1. require("anvil.*") works in other plugin specs
--   2. after/ftplugin/ from common is loaded automatically
--
-- This file computes the path to src/common relative to its own location:
--   src/astronvim/lua/plugins/anvil.lua  (this file)
--   src/common/                          (target)

local function get_common_path()
  local source = debug.getinfo(1, "S").source:sub(2)
  local plugins_dir = vim.fn.fnamemodify(source, ":h")     -- .../lua/plugins
  local lua_dir = vim.fn.fnamemodify(plugins_dir, ":h")     -- .../lua
  local astronvim_dir = vim.fn.fnamemodify(lua_dir, ":h")   -- .../astronvim
  local src_dir = vim.fn.fnamemodify(astronvim_dir, ":h")   -- .../src
  return src_dir .. "/common"
end

local common_path = get_common_path()

-- Verify common exists
if vim.fn.isdirectory(common_path .. "/lua") == 1 then
  require("anvil").inject_rtp(common_path)
else
  vim.notify(
    "[anvil] Common directory not found: " .. common_path,
    vim.log.levels.WARN
  )
end

-- This file does NOT return plugin specs.
-- Each plugin spec file reads anvil data directly via require("anvil.tools"), etc.
return {}
```

```lua
-- AstroLSP — LSP configuration.
-- Server SETTINGS come from anvil.servers (shared).
-- Server LIST comes from anvil.tools (shared).
-- Everything else (on_attach, capabilities, formatting) is AstroNvim-specific.
```

### `src/nvchad/lua/anvil_path.lua`

Minimal bridge — path resolution and rtp injection only.

<!-- file: src/nvchad/lua/anvil_path.lua -->
```lua
-- Anvil path resolver for NvChad.
-- Computes path to src/common and injects it into runtimepath.
--
-- Path structure:
--   src/nvchad/lua/anvil_path.lua  (this file)
--   src/common/                    (target)

local M = {}

function M.get_common_path()
  local source = debug.getinfo(1, "S").source:sub(2)
  local lua_dir = vim.fn.fnamemodify(source, ":h")        -- .../lua
  local nvchad_dir = vim.fn.fnamemodify(lua_dir, ":h")    -- .../nvchad
  local src_dir = vim.fn.fnamemodify(nvchad_dir, ":h")    -- .../src
  return src_dir .. "/common"
end

function M.inject()
  local common_path = M.get_common_path()
  if vim.fn.isdirectory(common_path .. "/lua") == 1 then
    require("anvil").inject_rtp(common_path)
  else
    vim.notify(
      "[anvil] Common directory not found: " .. common_path,
      vim.log.levels.WARN
    )
  end
end

return M
```

## Installation Script

### `install.sh`

<!-- file: install.sh -->
```bash
#!/usr/bin/env bash
set -euo pipefail

# ─── Colors ───
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
BLUE='\033[0;34m'
CYAN='\033[0;36m'
NC='\033[0m'

# ─── Script directory (repository root) ───
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
SRC_DIR="$SCRIPT_DIR/src"

# ─── Platform paths ───
case "$(uname -s)" in
  Linux|Darwin)
    NVIM_CONFIG_HOME="${XDG_CONFIG_HOME:-$HOME/.config}"
    NVIM_DATA_HOME="${XDG_DATA_HOME:-$HOME/.local/share}"
    NVIM_STATE_HOME="${XDG_STATE_HOME:-$HOME/.local/state}"
    NVIM_CACHE_HOME="${XDG_CACHE_HOME:-$HOME/.cache}"
    ;;
  MINGW*|MSYS*|CYGWIN*)
    NVIM_CONFIG_HOME="$LOCALAPPDATA"
    NVIM_DATA_HOME="$LOCALAPPDATA"
    NVIM_STATE_HOME="$LOCALAPPDATA"
    NVIM_CACHE_HOME="${TEMP:-/tmp}"
    ;;
  *)
    echo -e "${RED}Unsupported platform: $(uname -s)${NC}"
    exit 1
    ;;
esac

# ─── Logging ───
log_info()  { echo -e "${BLUE}[INFO]${NC} $*"; }
log_ok()    { echo -e "${GREEN}[ OK ]${NC} $*"; }
log_warn()  { echo -e "${YELLOW}[WARN]${NC} $*"; }
log_err()   { echo -e "${RED}[ERR ]${NC} $*"; }

print_header() {
  echo -e "${CYAN}"
  echo "  ╔═══════════════════════════════════════╗"
  echo "  ║           ⚒  ANVIL v2  ⚒             ║"
  echo "  ║    Unified Neovim Configuration       ║"
  echo "  ╚═══════════════════════════════════════╝"
  echo -e "${NC}"
}

# ─── Dependency check ───
check_deps() {
  local missing=()
  command -v git  &>/dev/null || missing+=("git")
  command -v nvim &>/dev/null || missing+=("nvim")

  if [[ ${#missing[@]} -gt 0 ]]; then
    log_err "Missing dependencies: ${missing[*]}"
    log_info "Run ./preinstall.sh first"
    exit 1
  fi

  # Check neovim version (need 0.10+ for NVIM_APPNAME)
  local nvim_ver
  nvim_ver=$(nvim --version | head -1 | grep -oP 'v\K[0-9]+\.[0-9]+' || true)
  if [[ -n "$nvim_ver" ]]; then
    local major minor
    major=$(echo "$nvim_ver" | cut -d. -f1)
    minor=$(echo "$nvim_ver" | cut -d. -f2)
    if [[ $major -eq 0 && $minor -lt 10 ]]; then
      log_err "Neovim v0.10+ required (found v$nvim_ver)"
      exit 1
    fi
  fi

  log_ok "Dependencies OK (nvim ${nvim_ver:-unknown})"
}

# ─── Symlink creation ───
create_symlink() {
  local source="$1"
  local target="$2"

  if [[ -L "$target" ]]; then
    local current
    current=$(readlink -f "$target" 2>/dev/null || readlink "$target")
    local resolved
    resolved=$(readlink -f "$source" 2>/dev/null || echo "$source")

    if [[ "$current" == "$resolved" ]]; then
      log_ok "Symlink OK: $target"
      return 0
    else
      log_warn "Updating symlink: $target"
      rm "$target"
    fi
  elif [[ -e "$target" ]]; then
    local backup="${target}.bak.$(date +%Y%m%d%H%M%S)"
    log_warn "Backing up existing: $target -> $backup"
    mv "$target" "$backup"
  fi

  mkdir -p "$(dirname "$target")"
  ln -s "$source" "$target"
  log_ok "Symlink: $target -> $source"
}

# ─── Clean data ───
clean_data() {
  local appname="$1"
  local dirs=(
    "$NVIM_DATA_HOME/$appname"
    "$NVIM_STATE_HOME/$appname"
    "$NVIM_CACHE_HOME/$appname"
  )
  for dir in "${dirs[@]}"; do
    if [[ -d "$dir" ]]; then
      log_info "Removing: $dir"
      rm -rf "$dir"
    fi
  done
}

# ─── Available frameworks ───
list_frameworks() {
  local frameworks=()
  for dir in "$SRC_DIR"/*/; do
    local name
    name=$(basename "$dir")
    [[ "$name" == "common" ]] && continue
    frameworks+=("$name")
  done
  echo "${frameworks[@]}"
}

# ─── Commands ───

cmd_install() {
  local framework="$1"
  local appname="${2:-anvil-$framework}"

  if [[ ! -d "$SRC_DIR/$framework" ]]; then
    log_err "Framework '$framework' not found"
    log_info "Available: $(list_frameworks)"
    exit 1
  fi

  log_info "Installing '$framework' as NVIM_APPNAME='$appname'"

  create_symlink "$SRC_DIR/$framework" "$NVIM_CONFIG_HOME/$appname"

  if [[ ! -d "$SRC_DIR/common/lua" ]]; then
    log_warn "Common directory not found — shared config unavailable"
  else
    log_ok "Common config: $SRC_DIR/common"
  fi

  echo ""
  echo -e "  Run: ${GREEN}NVIM_APPNAME=$appname nvim${NC}"
  echo -e "  Alias: ${CYAN}alias $appname='NVIM_APPNAME=$appname nvim'${NC}"
}

cmd_install_default() {
  local framework="$1"

  if [[ ! -d "$SRC_DIR/$framework" ]]; then
    log_err "Framework '$framework' not found"
    exit 1
  fi

  log_info "Installing '$framework' as default nvim"
  create_symlink "$SRC_DIR/$framework" "$NVIM_CONFIG_HOME/nvim"
  echo -e "  Run: ${GREEN}nvim${NC}"
}

cmd_install_all() {
  log_info "Installing all frameworks"
  for name in $(list_frameworks); do
    cmd_install "$name" "anvil-$name"
    echo ""
  done
  log_ok "All installed"
}

cmd_uninstall() {
  local appname="$1"
  local target="$NVIM_CONFIG_HOME/$appname"

  if [[ -L "$target" ]]; then
    rm "$target"
    log_ok "Removed: $target"
  elif [[ -e "$target" ]]; then
    log_warn "$target is not a symlink — refusing to remove"
    return 1
  else
    log_warn "Nothing to remove: $target"
    return 0
  fi

  read -rp "Clean data/state/cache for '$appname'? [y/N] " answer
  if [[ "$answer" =~ ^[Yy]$ ]]; then
    clean_data "$appname"
  fi
}

cmd_status() {
  echo -e "${CYAN}Anvil Status${NC}"
  echo ""

  local nvim_config="$NVIM_CONFIG_HOME/nvim"
  if [[ -L "$nvim_config" ]]; then
    echo -e "  default (nvim): ${GREEN}→ $(readlink "$nvim_config")${NC}"
  elif [[ -d "$nvim_config" ]]; then
    echo -e "  default (nvim): ${YELLOW}exists (not anvil)${NC}"
  else
    echo -e "  default (nvim): ${RED}not configured${NC}"
  fi

  for dir in "$NVIM_CONFIG_HOME"/anvil-*/; do
    [[ -e "$dir" ]] || continue
    local name
    name=$(basename "$dir")
    if [[ -L "${dir%/}" ]]; then
      echo -e "  $name: ${GREEN}→ $(readlink "${dir%/}")${NC}"
    else
      echo -e "  $name: ${YELLOW}exists (not symlink)${NC}"
    fi
  done

  echo ""
  echo -e "${CYAN}Source:${NC}"
  for dir in "$SRC_DIR"/*/; do
    echo "  $(basename "$dir"): $dir"
  done
}

cmd_bootstrap() {
  local appname="${1:-nvim}"
  log_info "Bootstrapping '$appname'..."
  NVIM_APPNAME="$appname" nvim --headless +"Lazy! sync" +qall 2>&1 || true
  log_ok "Bootstrap complete: $appname"
}

cmd_shell_setup() {
  echo "# Anvil Neovim aliases — add to ~/.bashrc or ~/.zshrc"
  echo ""
  for name in $(list_frameworks); do
    echo "alias anvil-$name='NVIM_APPNAME=anvil-$name nvim'"
  done
  echo ""
  echo '# Switch function: anvil astronvim [files...]'
  echo 'anvil() {'
  echo '  local config="${1:-astronvim}"'
  echo '  shift 2>/dev/null || true'
  echo '  NVIM_APPNAME="anvil-${config}" nvim "$@"'
  echo '}'
}

# ─── Usage ───
usage() {
  echo "Usage: $0 <command> [args]"
  echo ""
  echo "Commands:"
  echo "  install <framework> [appname]  Install as isolated NVIM_APPNAME"
  echo "  install-default <framework>    Install as default nvim config"
  echo "  install-all                    Install all frameworks"
  echo "  uninstall <appname>            Remove installation"
  echo "  status                         Show current installations"
  echo "  bootstrap [appname]            Initialize plugins headlessly"
  echo "  shell-setup                    Print shell aliases"
  echo "  clean <appname>                Remove data/state/cache"
  echo "  help                           This message"
  echo ""
  echo "Frameworks: $(list_frameworks)"
}

# ─── Main ───
main() {
  print_header
  check_deps

  local cmd="${1:-help}"
  shift 2>/dev/null || true

  case "$cmd" in
    install)
      [[ $# -lt 1 ]] && { log_err "Framework required"; usage; exit 1; }
      cmd_install "$@"
      ;;
    install-default)
      [[ $# -lt 1 ]] && { log_err "Framework required"; usage; exit 1; }
      cmd_install_default "$@"
      ;;
    install-all)      cmd_install_all ;;
    uninstall)
      [[ $# -lt 1 ]] && { log_err "Appname required"; usage; exit 1; }
      cmd_uninstall "$@"
      ;;
    status)           cmd_status ;;
    bootstrap)        cmd_bootstrap "${1:-nvim}" ;;
    shell-setup)      cmd_shell_setup ;;
    clean)
      [[ $# -lt 1 ]] && { log_err "Appname required"; usage; exit 1; }
      clean_data "$1"
      log_ok "Cleaned: $1"
      ;;
    help|--help|-h)   usage ;;
    *)
      log_err "Unknown command: $cmd"
      usage
      exit 1
      ;;
  esac
}

main "$@"
```

## How It Works

### Common Connection Mechanism

```
┌──────────────────────────────────────────────────────────┐
│                    NVIM_APPNAME                          │
│           (anvil-astronvim or anvil-nvchad)              │
└────────────────────────┬─────────────────────────────────┘
                         │
                         ▼
┌──────────────────────────────────────────────────────────┐
│  src/astronvim/init.lua  or  src/nvchad/init.lua         │
│  (original bootstrap — unchanged for AstroNvim,          │
│   one line added for NvChad)                             │
└────────────────────────┬─────────────────────────────────┘
                         │
                         ▼
┌──────────────────────────────────────────────────────────┐
│  Bridge file (anvil.lua or anvil_path.lua)               │
│  1. Computes path to src/common via debug.getinfo        │
│  2. Calls require("anvil").inject_rtp(common_path)       │
│  3. That's it — no plugin specs, no setup calls          │
└──────────┬───────────────────────┬───────────────────────┘
           │                       │
           ▼                       ▼
┌────────────────────┐  ┌──────────────────────────────────┐
│  src/common/       │  │  Framework-specific plugin specs  │
│  lua/anvil/        │  │  read DATA from anvil:            │
│  ├── tools.lua     │  │                                   │
│  ├── servers.lua   │◄─┤  require("anvil.tools")           │
│  ├── formatters.lua│  │  require("anvil.servers")         │
│  └── linters.lua   │  │  require("anvil.formatters")      │
│                    │  │                                   │
│  after/ftplugin/   │  │  Mappings, options, autocmds      │
│  (auto-loaded      │  │  are defined LOCALLY in each      │
│   via runtimepath) │  │  framework — not shared.          │
└────────────────────┘  └──────────────────────────────────┘
```

### Why Symlinks, Not Copying

A symlink `~/.config/anvil-astronvim → repo/src/astronvim` means:

- **Relative paths in the bridge work** — `debug.getinfo` returns the real
  path through the symlink, and `../common` resolves correctly
- **Changes in the repository are immediately visible** — no resync needed
- **Git tracks everything in one place**

### Isolation via NVIM\_APPNAME

Neovim 0.10+ supports `NVIM_APPNAME`, providing full isolation:

```
NVIM_APPNAME=anvil-astronvim
  config: ~/.config/anvil-astronvim/
  data:   ~/.local/share/anvil-astronvim/
  state:  ~/.local/state/anvil-astronvim/
  cache:  ~/.cache/anvil-astronvim/

NVIM_APPNAME=anvil-nvchad
  config: ~/.config/anvil-nvchad/
  data:   ~/.local/share/anvil-nvchad/
  state:  ~/.local/state/anvil-nvchad/
  cache:  ~/.cache/anvil-nvchad/

nvim (default, without NVIM_APPNAME)
  config: ~/.config/nvim/
  data:   ~/.local/share/nvim/
```

All configurations work completely independently — their own plugins, cache,
and state.

## Extending the Shared Configuration

### Adding a new LSP server

Edit `src/common/lua/anvil/tools.lua` (add to lists) and
`src/common/lua/anvil/servers.lua` (add settings):

```lua
-- tools.lua: add to M.lsp_servers
M.lsp_servers = {
  -- ... existing ...
  "rust_analyzer",
}

-- tools.lua: add to M.mason_ensure_installed
M.mason_ensure_installed = {
  -- ... existing ...
  "rust-analyzer",
}

-- servers.lua: add settings
M.rust_analyzer = {
  settings = {
    ["rust-analyzer"] = {
      checkOnSave = { command = "clippy" },
    },
  },
}
```

Both frameworks pick up the changes on next launch — no framework files
need editing.

### Adding a new formatter

Edit `src/common/lua/anvil/formatters.lua`:

```lua
M.formatters_by_ft = {
  -- ... existing ...
  rust = { "rustfmt" },
}
```

### Adding a new ftplugin

Create a file in `src/common/after/ftplugin/`:

```lua
-- src/common/after/ftplugin/rust.lua
vim.opt_local.tabstop = 4
vim.opt_local.shiftwidth = 4
```

This is automatically loaded in both frameworks via runtimepath.

## Architecture Decision Record

### Why NOT share plugin specs

Both AstroNvim and NvChad use lazy.nvim, so plugin specs have the same
format. However, sharing them causes problems:

1. **Duplicate specs.** AstroNvim includes nvim-autopairs, gitsigns, etc.
   Adding the same plugin from common creates a duplicate spec that
   lazy.nvim merges unpredictably (`event`, `cmd`, `keys` may conflict).

2. **Version drift.** A framework may pin a plugin version or use a fork.
   A common spec with `version = "*"` may override this.

3. **Framework-specific config.** AstroNvim configures treesitter via
   `astrotreesitter`, NvChad via direct opts. A common treesitter spec
   creates a third configuration path.

4. **Testing burden.** Every shared plugin must be tested against both
   frameworks on every update.

### Why NOT share keymaps

1. **Different APIs.** AstroNvim: declarative `astrocore.opts.mappings`.
   NvChad: imperative `vim.keymap.set`. A converter function
   (`to_astrocore_format`) only works for trivial cases.

2. **Buffer-local mappings.** AstroNvim handles these via `astrocore`
   with `buffer` key. NvChad uses `{ buffer = bufnr }` in on\_attach.
   Incompatible formats.

3. **Conditional mappings.** AstroNvim supports `cond = function()` in
   mapping specs. NvChad requires manual `if` checks.

4. **Which-key integration.** Different APIs, different group definitions.

### Why share LSP server settings

1. **Universal format.** `lspconfig[server].setup(opts)` is the same
   regardless of framework. The `settings` table is server-specific,
   not framework-specific.

2. **High value.** Server settings (diagnostics, workspace config,
   inlay hints) are the most tedious to maintain and most likely to
   be identical across frameworks.

3. **No conflict.** Each framework merges these settings with its own
   defaults (capabilities, on\_attach) — no overlap.

### Why share formatter configs

1. **Both use conform.nvim.** The `formatters_by_ft` format is identical.

2. **Pure data.** No callbacks, no framework-specific hooks.

3. **Single source of truth.** Changing a formatter arg (e.g., black
   line length) should take effect everywhere.
