# Anvil — AI Ecosystem

The AI layer is a first-class subsystem in Anvil, designed to replace GitHub Copilot, Cline, and Claude Code with open-source alternatives using any OpenAI-compatible provider.

## Tool Selection Guide

| Task | Tool | Why |
|---|---|---|
| Quick question about code | CodeCompanion chat | Fast, integrated, buffer context |
| Fix diagnostics / errors | CodeCompanion `/fix` | Sees LSP diagnostics directly |
| Explain error under cursor | wtf.nvim | One keypress, instant popup |
| Code review | CodeCompanion `/review` | Full file + diagnostics |
| Generate tests | CodeCompanion `/gentest` | Understands project test patterns |
| Inline completion | minuet-ai (`F2` toggle) | Non-intrusive, opt-in |
| Multi-file refactoring | Aider | Best at editing multiple files |
| Complex feature with planning | OpenCode | Built-in planner + sub-agents |
| Explore unfamiliar codebase | CodeCompanion + MCP | MCP reads files, fetches docs |
| Database queries / schema | CodeCompanion + MCP | postgres MCP server |
| Read external documentation | CodeCompanion `/url` | Fetches and converts to text |
| Switch AI for different project | `:AnvilPreset` | Instant provider/model switch |

## Provider System

### Concepts

```text
┌─────────────────────────────────────────────────────────┐
│  PROVIDER = endpoint + credentials                       │
│  ├── openrouter  (https://openrouter.ai/api/v1)         │
│  ├── ollama      (http://localhost:11434/v1)             │
│  └── corporate   (https://llm.corp.internal/v1)         │
├─────────────────────────────────────────────────────────┤
│  MODEL = specific model on a provider                    │
│  ├── openrouter/claude-sonnet (anthropic/claude-sonnet-4)│
│  ├── openrouter/claude-haiku  (anthropic/claude-haiku)   │
│  ├── ollama/qwen-coder        (qwen2.5-coder:14b)       │
│  └── corporate/internal-llm   (corp-llm-v2)             │
├─────────────────────────────────────────────────────────┤
│  SLOT = interaction type → model assignment              │
│  ├── chat       (general conversations)                  │
│  ├── inline     (code completions, minuet-ai)            │
│  ├── agent      (autonomous agents)                      │
│  ├── architect  (planning, large context)                │
│  ├── fast       (quick tasks, commit msgs)               │
│  └── local      (privacy-sensitive, always local)        │
├─────────────────────────────────────────────────────────┤
│  PRESET = named set of slot→model assignments            │
│  ├── default     (cloud + local)                         │
│  ├── corporate   (private provider only)                 │
│  └── local-only  (Ollama only)                           │
└─────────────────────────────────────────────────────────┘
```

### Resolution Order

When an AI tool needs credentials for a slot:

1. **Session override** — temporary, set via `:AnvilSlot chat <model>` with "session only"
2. **Active preset** — the currently selected preset's slot assignment
3. **Fallback** — if slot is not configured, falls back to the `chat` slot

### Preset Scenarios

**Corporate project** (closed network):
`:AnvilPreset corporate`
→ All slots use `corporate/internal-llm`
→ No data leaves the corporate network
→ Local slot still uses Ollama for offline work

**Standard development**:
`:AnvilPreset default`
→ Chat/agents use Claude Sonnet (cloud)
→ Inline completions use Claude Haiku (fast, cheap)
→ Local slot uses Ollama

**Open-source project** (sponsored):
`:AnvilPreset opensource`
→ All slots use the sponsor's provider
→ Custom preset saved with `:AnvilSavePreset`

**Quick model swap for one task**:
`:AnvilSlot architect openrouter/claude-sonnet`
→ Only architect mode changes (session override)
→ Other slots unchanged
→ Not persisted — reverts on restart

Provider registry, models, slots, presets, and UI for switching.

```lua
--- Anvil AI provider configuration
--- Provider registry, models, slots, presets — all from JSON config
--- Single source of truth for all AI endpoints and models
---@class AnvilAIProviders
local M = {}

local logger = require("anvil.core.logger")

---@type string
M._config_path = vim.fn.stdpath("config") .. "/config/ai-providers.json"

---@type table|nil
M._data = nil

---@type table<string, string>  slot → model_id (session overrides, not persisted)
M._session_overrides = {}

--- Slot names in canonical order
---@type string[]
M._slot_names = { "chat", "inline", "agent", "architect", "fast", "local" }

--- Return config file path
---@return string
function M.config_path()
  return M._config_path
end

--- Return slot names
---@return string[]
function M.slot_names()
  return M._slot_names
end

--- Load config from JSON file
---@param force? boolean reload even if already loaded
function M.load(force)
  if M._data and not force then return end

  local path = M._config_path
  if vim.fn.filereadable(path) ~= 1 then
    logger.warn("AI config not found: %s — using built-in defaults", path)
    M._data = M._builtin_defaults()
    return
  end

  local content = table.concat(vim.fn.readfile(path), "\n")
  local ok, decoded = pcall(vim.json.decode, content)
  if not ok then
    logger.error("Failed to parse AI config: %s", decoded)
    M._data = M._builtin_defaults()
    return
  end

  M._data = decoded
  logger.debug("AI config loaded from %s", path)
end

--- Save current config to JSON file
function M.save()
  if not M._data then return end
  local path = M._config_path
  local dir = vim.fn.fnamemodify(path, ":h")
  if vim.fn.isdirectory(dir) == 0 then
    vim.fn.mkdir(dir, "p")
  end
  local encoded = vim.json.encode(M._data)
  -- Pretty-print JSON
  local formatted = vim.fn.system({ "python3", "-m", "json.tool" }, encoded)
  if vim.v.shell_error ~= 0 then
    formatted = encoded
  end
  vim.fn.writefile(vim.split(formatted, "\n"), path)
  logger.info("AI config saved to %s", path)
end

--- Ensure data is loaded
local function ensure_loaded()
  if not M._data then M.load() end
end

--- Get active preset
---@return table { name: string, description: string, slots: table<string,string> }
function M.active_preset()
  ensure_loaded()
  local name = M._data.active_preset or "default"
  return M._data.presets[name] or M._data.presets["default"] or { name = "unknown", slots = {} }
end

--- Set active preset
---@param name string preset name
function M.set_preset(name)
  ensure_loaded()
  if not M._data.presets[name] then
    logger.error("Preset not found: %s", name)
    return
  end
  M._data.active_preset = name
  M._session_overrides = {}
  M.save()
  logger.info("Switched to preset: %s", name)
  require("anvil.core.events").emit("ai:preset_changed", { preset = name })
end

--- Resolve a slot to { provider: table, model: table }
---@param slot string slot name
---@return { provider: table, model: table }|nil
function M.resolve(slot)
  ensure_loaded()

  -- 1. Session override
  local model_id = M._session_overrides[slot]

  -- 2. Active preset
  if not model_id then
    local preset = M.active_preset()
    model_id = preset.slots and preset.slots[slot]
  end

  -- 3. Fallback to chat slot
  if not model_id and slot ~= "chat" then
    local preset = M.active_preset()
    model_id = preset.slots and preset.slots["chat"]
  end

  if not model_id then return nil end

  local model_def = M._data.models[model_id]
  if not model_def then
    logger.warn("Model not found: %s", model_id)
    return nil
  end

  local provider_def = M._data.providers[model_def.provider]
  if not provider_def then
    logger.warn("Provider not found: %s", model_def.provider)
    return nil
  end

  return { provider = provider_def, model = model_def }
end

--- Build HTTP headers for a slot
---@param slot string
---@return table
function M.headers_for(slot)
  local resolved = M.resolve(slot)
  if not resolved then return { ["Content-Type"] = "application/json" } end
  local h = {
    ["Content-Type"]  = "application/json",
    ["Authorization"] = "Bearer " .. (resolved.provider.api_key or ""),
  }
  if resolved.provider.headers then
    for k, v in pairs(resolved.provider.headers) do
      h[k] = v
    end
  end
  return h
end

--- Set session override for a slot
---@param slot string
---@param model_id string
function M.set_session_override(slot, model_id)
  ensure_loaded()
  if not M._data.models[model_id] then
    logger.error("Model not found: %s", model_id)
    return
  end
  M._session_overrides[slot] = model_id
  logger.info("Session override: %s → %s", slot, model_id)
  require("anvil.core.events").emit("ai:slot_changed", { slot = slot, model = model_id })
end

--- Clear session override for a slot
---@param slot string
function M.clear_session_override(slot)
  M._session_overrides[slot] = nil
end

--- Get list of all model IDs
---@return string[]
function M.model_ids()
  ensure_loaded()
  local ids = {}
  for id in pairs(M._data.models or {}) do
    ids[#ids + 1] = id
  end
  table.sort(ids)
  return ids
end

--- Get list of all preset names
---@return string[]
function M.preset_names()
  ensure_loaded()
  local names = {}
  for name in pairs(M._data.presets or {}) do
    names[#names + 1] = name
  end
  table.sort(names)
  return names
end

--- Save current slot assignments as a new preset
---@param name string
---@param description? string
function M.save_as_preset(name, description)
  ensure_loaded()
  local current = M.active_preset()
  local new_slots = vim.deepcopy(current.slots or {})
  -- Apply session overrides
  for slot, model_id in pairs(M._session_overrides) do
    new_slots[slot] = model_id
  end
  M._data.presets[name] = {
    name = name,
    description = description or ("Custom preset: " .. name),
    slots = new_slots,
  }
  M._data.active_preset = name
  M._session_overrides = {}
  M.save()
  logger.info("Saved and activated preset: %s", name)
end

--- Show current configuration
function M.show_config()
  ensure_loaded()
  local preset = M.active_preset()
  local lines = {
    "╭─── Anvil AI Providers ───╮",
    "│ Preset: " .. preset.name,
    "│ " .. (preset.description or ""),
    "│",
  }
  for _, slot in ipairs(M._slot_names) do
    local resolved = M.resolve(slot)
    if resolved then
      local override = M._session_overrides[slot] and " (session)" or ""
      lines[#lines + 1] = string.format(
        "│  %-12s → %s (%s)%s",
        slot, resolved.model.model, resolved.provider.name, override
      )
    else
      lines[#lines + 1] = string.format("│  %-12s → (not configured)", slot)
    end
  end
  lines[#lines + 1] = "╰──────────────────────────╯"
  vim.notify(table.concat(lines, "\n"), vim.log.levels.INFO, { title = "Anvil AI" })
end

--- Interactive preset picker
function M.pick_preset()
  ensure_loaded()
  local names = M.preset_names()
  local items = {}
  for _, name in ipairs(names) do
    local p = M._data.presets[name]
    items[#items + 1] = name .. " — " .. (p.description or "")
  end
  vim.ui.select(items, { prompt = "Switch AI preset:" }, function(_, idx)
    if idx then M.set_preset(names[idx]) end
  end)
end

--- Interactive slot model picker
---@param slot? string if nil, pick slot first
function M.pick_slot(slot)
  ensure_loaded()
  if not slot then
    vim.ui.select(M._slot_names, { prompt = "Pick slot:" }, function(choice)
      if choice then M.pick_slot(choice) end
    end)
    return
  end
  local model_ids = M.model_ids()
  local items = {}
  for _, id in ipairs(model_ids) do
    local m = M._data.models[id]
    items[#items + 1] = id .. " — " .. (m.description or m.model)
  end
  vim.ui.select(items, { prompt = "Model for " .. slot .. ":" }, function(_, idx)
    if idx then M.set_session_override(slot, model_ids[idx]) end
  end)
end

--- Register provider commands
function M.register_commands()
  local cmd = vim.api.nvim_create_user_command

  cmd("AnvilPreset", function(args)
    if args.args and args.args ~= "" then
      M.set_preset(args.args)
    else
      M.pick_preset()
    end
  end, {
    nargs = "?",
    complete = function() return M.preset_names() end,
    desc = "Anvil: Switch AI preset",
  })

  cmd("AnvilSlot", function(args)
    local parts = vim.split(args.args or "", "%s+", { trimempty = true })
    if #parts == 0 then
      M.pick_slot()
    elseif #parts == 1 then
      M.pick_slot(parts[1])
    else
      M.set_session_override(parts[1], parts[2])
    end
  end, {
    nargs = "*",
    complete = function(_, line)
      local parts = vim.split(line, "%s+", { trimempty = true })
      if #parts <= 2 then return M._slot_names end
      return M.model_ids()
    end,
    desc = "Anvil: Change slot model",
  })

  cmd("AnvilSavePreset", function()
```

```lua
--- Anvil AI context builder
--- Collects context from editor state for AI prompts
---@class AnvilAIContext
local M = {}

local cache = require("anvil.core.cache")

--- Get diagnostics for a buffer
---@param bufnr? number buffer number (0 = current)
---@return string
function M.get_diagnostics(bufnr)
  bufnr = bufnr or 0
  local diagnostics = vim.diagnostic.get(bufnr)
  if #diagnostics == 0 then return "" end

  local lines = { "## Diagnostics\n" }
  for _, d in ipairs(diagnostics) do
    local severity = vim.diagnostic.severity[d.severity] or "UNKNOWN"
    lines[#lines + 1] = string.format(
      "- [%s] Line %d: %s%s",
      severity, d.lnum + 1, d.message,
      d.source and (" (%s)"):format(d.source) or ""
    )
  end
  return table.concat(lines, "\n")
end

--- Get all project diagnostics (errors only)
---@return string
function M.get_project_errors()
  local diagnostics = vim.diagnostic.get(nil, {
    severity = vim.diagnostic.severity.ERROR,
  })
  if #diagnostics == 0 then return "" end

  local lines = { "## Project Errors\n" }
  for _, d in ipairs(diagnostics) do
    local fname = vim.fn.fnamemodify(
      vim.api.nvim_buf_get_name(d.bufnr), ":~:."
    )
    lines[#lines + 1] = string.format(
      "- %s:%d — %s%s",
      fname, d.lnum + 1, d.message,
      d.source and (" (%s)"):format(d.source) or ""
    )
  end
  return table.concat(lines, "\n")
end

--- Get test results from neotest
---@return string
function M.get_test_results()
  local ok, neotest = pcall(require, "neotest")
  if not ok then return "" end

  local client = neotest.state
  if not client then return "" end

  local adapter_ids = client.adapter_ids()
  if #adapter_ids == 0 then return "" end

  local lines = { "## Test Results\n" }
  local has_failures = false

  for _, adapter_id in ipairs(adapter_ids) do
    local results = client.results(adapter_id)
    if results then
      for test_id, result in pairs(results) do
        if result.status == "failed" then
          has_failures = true
          lines[#lines + 1] = string.format("- FAILED: %s", test_id)
          if result.short then
            lines[#lines + 1] = "  ```\n  " .. result.short .. "\n  ```"
          end
          if result.errors then
            for _, err in ipairs(result.errors) do
              lines[#lines + 1] = string.format(
                "  Error at line %d: %s",
                err.line or 0, err.message
              )
            end
          end
        end
      end
    end
  end

  if not has_failures then
    lines[#lines + 1] = "All tests passed ✓"
  end

  return table.concat(lines, "\n")
end

--- Get treesitter context (current function/class)
---@return string
function M.get_treesitter_context()
  local node = vim.treesitter.get_node()
  if not node then return "" end

  local function_node = nil
  local class_node    = nil
  local current       = node

  while current do
    local ntype = current:type()
    if ntype:match("function") or ntype:match("method")
      or ntype == "function_definition"
      or ntype == "function_declaration"
      or ntype == "method_definition"
      or ntype == "arrow_function" then
      function_node = function_node or current
    elseif ntype:match("class")
      or ntype == "class_definition"
      or ntype == "class_declaration"
      or ntype == "impl_item"
      or ntype == "struct_item" then
      class_node = class_node or current
    end
    current = current:parent()
  end

  if not function_node and not class_node then return "" end

  local parts = { "## Current Context (Treesitter)\n" }

  if class_node then
    local start_row = class_node:start()
    local text = vim.treesitter.get_node_text(class_node, 0)
    local class_lines = vim.split(text, "\n")
    if #class_lines > 5 then
      text = table.concat(vim.list_slice(class_lines, 1, 5), "\n") .. "\n  ..."
    end
    parts[#parts + 1] = string.format("Class (line %d):\n```\n%s\n```\n", start_row + 1, text)
  end

  if function_node then
    local start_row = function_node:start()
    local text = vim.treesitter.get_node_text(function_node, 0)
    parts[#parts + 1] = string.format("Function (line %d):\n```\n%s\n```\n", start_row + 1, text)
  end

  return table.concat(parts, "\n")
end

--- Get git diff
---@return string
function M.get_git_diff()
  local diff = vim.fn.system("git diff --stat HEAD 2>/dev/null")
  if vim.v.shell_error ~= 0 or diff == "" then return "" end

  local detailed = vim.fn.system("git diff HEAD 2>/dev/null")
  if #detailed > 5000 then
    detailed = detailed:sub(1, 5000) .. "\n... (truncated)"
  end

  return "## Git Changes\n\n```diff\n" .. detailed .. "\n```\n"
end

--- Get project structure and key files (cached)
---@param root? string project root (default: cwd)
---@return string
function M.get_project_index(root)
  root = root or vim.fn.getcwd()
  local cache_key = "project_index:" .. root

  return cache.get_or_set(cache_key, function()
    return M._build_project_index(root)
  end, 3600)  -- 1 hour TTL
end

--- Build project index (internal)
---@param root string
---@return string
function M._build_project_index(root)
  local parts = {}

  -- File tree
  local tree_cmd
  if vim.fn.executable("fd") == 1 then
    tree_cmd = string.format(
      "fd --base-directory %s --max-depth 4 --type f --strip-cwd-prefix "
        .. "--exclude .git --exclude node_modules --exclude __pycache__ "
        .. "--exclude .venv --exclude target --exclude dist --exclude build "
        .. "| head -500 | sort",
      vim.fn.shellescape(root)
    )
  else
    tree_cmd = string.format(
      "find %s -maxdepth 4 -type f "
        .. "-not -path '*/.git/*' -not -path '*/node_modules/*' "
        .. "-not -path '*/__pycache__/*' -not -path '*/.venv/*' "
        .. "| head -500 | sed 's|^%s/||' | sort",
      vim.fn.shellescape(root),
      vim.fn.escape(root, "|/")
    )
  end

  local tree = vim.fn.system(tree_cmd)
  parts[#parts + 1] = "## Project Structure\n\n```\n" .. tree .. "\n```"

  -- Key files
  local key_files = {
    "README.md", "README.rst",
    "package.json", "Cargo.toml", "go.mod", "pyproject.toml", "setup.py",
    "Makefile", "Dockerfile", "docker-compose.yml",
    "tsconfig.json", "biome.json", ".editorconfig",
  }

  for _, file in ipairs(key_files) do
    local path = root .. "/" .. file
    if vim.fn.filereadable(path) == 1 then
      local content = vim.fn.readfile(path)
      if #content > 100 then
        content = vim.list_slice(content, 1, 100)
        content[#content + 1] = "... (truncated)"
      end
      parts[#parts + 1] = string.format(
        "## %s\n\n```\n%s\n```\n",
        file, table.concat(content, "\n")
      )
    end
  end

  return table.concat(parts, "\n")
end

--- Force re-index project
---@param root? string
function M.index_project(root)

  local cache_key = "project_index:" .. root
  cache.del(cache_key)
  M.get_project_index(root)

  local logger = require("anvil.core.logger")
  logger.info("Project indexed: %s", root)
end

--- Build full context from multiple sources
---@param opts? { diagnostics?: boolean, tests?: boolean, treesitter?: boolean, git?: boolean, project?: boolean, project_errors?: boolean }
---@return string
function M.build(opts)
  opts = vim.tbl_extend("force", {
    diagnostics     = true,
    tests           = false,
    treesitter      = true,
    git             = false,
    project         = false,
    project_errors  = false,
  }, opts or {})

  local parts = {}

  if opts.project then
    local idx = M.get_project_index()
    if idx ~= "" then parts[#parts + 1] = idx end
  end

  if opts.treesitter then
    local ts = M.get_treesitter_context()
    if ts ~= "" then parts[#parts + 1] = ts end
  end

  if opts.diagnostics then
    local diag = M.get_diagnostics()
    if diag ~= "" then parts[#parts + 1] = diag end
  end

  if opts.project_errors then
    local errs = M.get_project_errors()
    if errs ~= "" then parts[#parts + 1] = errs end
  end

  if opts.tests then
    local tests = M.get_test_results()
    if tests ~= "" then parts[#parts + 1] = tests end
  end

  if opts.git then
    local git = M.get_git_diff()
    if git ~= "" then parts[#parts + 1] = git end
  end

  -- Add language-specific AI context
  local lang_ok, lang = pcall(require, "anvil.lang")
  if lang_ok then
    local ai_ctx = lang.ai_context()
    if ai_ctx and ai_ctx.system_prompt then
      parts[#parts + 1] = "## Language Guidelines\n\n" .. ai_ctx.system_prompt
    end
  end

  return table.concat(parts, "\n\n---\n\n")
end

return M
```

```lua
--- Anvil AI chat history
--- Persistence and browsing of past conversations
---@class AnvilAIHistory
local M = {}

local history_dir = vim.fn.stdpath("data") .. "/anvil-chat-history"

--- List saved chats
---@return table[] { path: string, name: string, date: string, timestamp: number }
function M.list()
  vim.fn.mkdir(history_dir, "p")
  local files = vim.fn.glob(history_dir .. "/*.md", false, true)

  local chats = {}
  for _, file in ipairs(files) do
    local name  = vim.fn.fnamemodify(file, ":t:r")
    local mtime = vim.fn.getftime(file)
    chats[#chats + 1] = {
      path      = file,
      name      = name,
      date      = os.date("%Y-%m-%d %H:%M", mtime),
      timestamp = mtime,
    }
  end

  table.sort(chats, function(a, b) return a.timestamp > b.timestamp end)
  return chats
end

--- Browse history with telescope or vim.ui.select
function M.pick()
  local chats = M.list()
  if #chats == 0 then
    vim.notify("No chat history found", vim.log.levels.INFO)
    return
  end

  local telescope_ok = pcall(require, "telescope.pickers")
  if telescope_ok then
    M._telescope_pick(chats)
  else
    M._select_pick(chats)
  end
end

--- Telescope picker (internal)
---@param chats table[]
function M._telescope_pick(chats)
  local pickers      = require("telescope.pickers")
  local finders      = require("telescope.finders")
  local conf         = require("telescope.config").values
  local actions      = require("telescope.actions")
  local action_state = require("telescope.actions.state")

  pickers.new({}, {
    prompt_title = "Anvil Chat History",
    finder = finders.new_table({
      results = chats,
      entry_maker = function(entry)
        return {
          value   = entry,
          display = entry.date .. " — " .. entry.name,
          ordinal = entry.name .. " " .. entry.date,
        }
      end,
    }),
    sorter = conf.generic_sorter({}),
    attach_mappings = function(prompt_bufnr)
      actions.select_default:replace(function()
        actions.close(prompt_bufnr)
        local selection = action_state.get_selected_entry()
        if selection then
          M.load_into_chat(selection.value.path)
        end
      end)
      return true
    end,
  }):find()
end

--- vim.ui.select fallback (internal)
---@param chats table[]
function M._select_pick(chats)
  local items = {}
  for _, chat in ipairs(chats) do
    items[#items + 1] = chat.date .. " — " .. chat.name
  end
  vim.ui.select(items, { prompt = "Load chat history:" }, function(_, idx)
    if idx then
      M.load_into_chat(chats[idx].path)
    end
  end)
end

--- Load a chat into CodeCompanion
---@param path string
function M.load_into_chat(path)
  local lines   = vim.fn.readfile(path)
  local content = table.concat(lines, "\n")

  vim.cmd("CodeCompanionChat")
  vim.defer_fn(function()
    local cc_ok, cc = pcall(require, "codecompanion")
    if not cc_ok then return end
    local chat = cc.last_chat()
    if chat then
      chat:add_message({
        role    = "user",
        content = "Previous conversation context:\n\n" .. content
          .. "\n\n---\nContinue from where we left off.",
      }, { visible = false })
      vim.notify("Chat history loaded", vim.log.levels.INFO)
    end
  end, 500)
end

--- Clean up old history
---@param days? number delete chats older than this (default: 30)
function M.cleanup(days)
  days = days or 30
  local cutoff  = os.time() - (days * 86400)
  local chats   = M.list()
  local removed = 0

  for _, chat in ipairs(chats) do
    if chat.timestamp < cutoff then
      vim.fn.delete(chat.path)
      removed = removed + 1
    end
  end

  vim.notify(
    string.format("Cleaned up %d chats older than %d days", removed, days),
    vim.log.levels.INFO
  )
end

return M
```

```lua
--- Anvil AI health check
--- :checkhealth anvil_ai
local M = {}

function M.check()
  vim.health.start("Anvil AI Ecosystem")

  -- ─── Provider System ───
  local prov_ok, providers = pcall(require, "anvil.ai.providers")
  if prov_ok then
    vim.health.ok("Provider system loaded")

    local config_path = providers.config_path()
    if vim.fn.filereadable(config_path) == 1 then
      vim.health.ok("Config file: " .. config_path)
    else
      vim.health.info("No config file — using built-in defaults")
    end

    providers.load()
    local preset = providers.active_preset()
    vim.health.ok("Active preset: " .. preset.name .. " — " .. (preset.description or ""))

    for _, slot in ipairs(providers.slot_names()) do
      local resolved = providers.resolve(slot)
      if resolved then
        local has_key = resolved.provider.api_key ~= ""
        vim.health.ok(string.format(
          "  %-12s → %s (%s) %s",
          slot,
          resolved.model.model,
          resolved.provider.name,
          has_key and "✓" or "⚠ no API key"
        ))
      else
        vim.health.warn("  " .. slot .. " → not configured")
      end
    end
  else
    vim.health.error("Failed to load provider system")
  end

  -- ─── Plugins ───
  vim.health.start("Anvil AI Plugins")
  local plugins = {
    { "codecompanion",    "CodeCompanion" },
    { "minuet",           "minuet-ai" },
    { "mcphub",           "MCPHub" },
    { "wtf",              "wtf.nvim" },
    { "toggleterm",       "ToggleTerm" },
    { "render-markdown",  "render-markdown" },
  }
  for _, p in ipairs(plugins) do
    if pcall(require, p[1]) then
      vim.health.ok(p[2] .. " loaded")
    else
      vim.health.warn(p[2] .. " not found — run :Lazy sync")
    end
  end

  -- ─── External Tools ───
  vim.health.start("Anvil AI External Tools")
  local tools = {
    { "aider",    "Aider (multi-file AI editing)" },
    { "opencode", "OpenCode (planning agent)" },
  }
  for _, t in ipairs(tools) do
    if vim.fn.executable(t[1]) == 1 then
      vim.health.ok(t[2])
    else
      vim.health.info(t[2] .. " not installed (optional)")
    end
  end

  -- ─── Utilities ───
  vim.health.start("Anvil AI Utilities")
  local utils = {
    { "pandoc", "pandoc (HTML→text)" },
    { "curl",   "curl (URL fetching)" },
    { "node",   "Node.js (for MCP servers)" },
    { "npm",    "npm (for MCP servers)" },
  }
  for _, u in ipairs(utils) do
    if vim.fn.executable(u[1]) == 1 then
      vim.health.ok(u[2])
    else
      vim.health.warn(u[2] .. " not found")
    end
  end

  -- ─── MCP Config ───
  vim.health.start("Anvil MCP Servers")
  local mcp_config = vim.fn.expand("~/.config/anvil/mcp-servers.json")
  if vim.fn.filereadable(mcp_config) == 1 then
    vim.health.ok("MCP config found: " .. mcp_config)
  else
    vim.health.warn("MCP config not found — create " .. mcp_config)
  end
end

return M
```
