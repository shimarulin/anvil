# Anvil — Lang: Bash

Bash/Shell scripting language pack.

## Summary

| Feature | Tool |
|---|---|
| LSP | `bashls` (bash-language-server) |
| Treesitter | `bash` |
| Formatter | `shfmt` |
| Linter | `shellcheck` |
| DAP | — |
| Test | — |

## Design Decisions

- **bashls** — Node.js-based Bash LSP. Provides completions, hover, and go-to-definition.
- **shfmt** — Go-based shell formatter. Configured for 2-space indent, POSIX compatibility.
- **shellcheck** — the gold standard for shell script linting. Catches common pitfalls (quoting, globbing, etc.).
- No DAP — shell script debugging is done with `set -x` and `bash -x`.
- No neotest — shell tests are typically run via `bats` or `shunit2` using overseer tasks.

### `lua/anvil/lang/bash.lua`

<!-- file: lua/anvil/lang/bash.lua -->
```lua
--- Anvil language pack: Bash
--- Shell scripting (bash, sh, zsh)
---@type AnvilLangPack
local M = {
  name = "bash",
  filetypes = { "sh", "bash", "zsh" },

  treesitter = { "bash" },

  lsp = {
    server = "bashls",
    settings = {
      bashIde = {
        globPattern = "*@(.sh|.inc|.bash|.command)",
      },
    },
  },

  formatter = {
    tool = "shfmt",
  },

  linter = {
    tool = "shellcheck",
  },

  tasks = {
    {
      name = "Bash: Run current file",
      cmd = { "bash", vim.fn.expand("%:p") },
      lang = "bash",
      filetypes = { "sh", "bash" },
    },
    {
      name = "Bash: Check syntax",
      cmd = { "bash", "-n", vim.fn.expand("%:p") },
      lang = "bash",
      filetypes = { "sh", "bash" },
    },
    {
      name = "Bash: ShellCheck",
      cmd = { "shellcheck", vim.fn.expand("%:p") },
      lang = "bash",
      filetypes = { "sh", "bash" },
    },
  },

  ai = {
    system_prompt = "This is a shell scripting project. "
      .. "Use bash with 'set -euo pipefail' for safety. "
      .. "Quote all variables. Use shellcheck-clean code. "
      .. "Prefer functions over inline code. Use shfmt formatting.",
    file_patterns = { ".bashrc", ".bash_profile", ".zshrc", "Makefile" },
    conventions = "snake_case for variables and functions. "
      .. "SCREAMING_SNAKE_CASE for constants and environment variables. "
      .. "Use [[ ]] instead of [ ]. Use $() instead of backticks.",
  },
}

return M
```
