# Anvil — Lang: Lua

Lua language pack for Neovim plugin/configuration development.

## Summary

| Feature | Tool |
|---|---|
| LSP | `lua_ls` (lua-language-server) |
| Treesitter | `lua`, `luadoc`, `luap` |
| Formatter | `stylua` |
| Linter | `selene` |
| DAP | — |
| Test | — |
| Extra plugins | `lazydev.nvim`, `luvit-meta` |

## Design Decisions

- **lua_ls** — the only production-quality Lua LSP. Anvil's `.luarc.json` configures it for Neovim development (vim.* globals, luv types, busted test globals).
- **stylua** — Rust-based Lua formatter. Configured via `stylua.toml` at project root.
- **selene** — Rust-based Lua linter (ADR-018). Understands `vim` global via `selene.toml` + `selene/vim.yml`.
- **lazydev.nvim** — provides runtime type information for Neovim plugins (ADR-016). Replaces deprecated neodev.nvim.
- No DAP — Lua debugging in Neovim context is impractical; use `print()` / `vim.inspect()`.
- No neotest — Neovim Lua tests use plenary.busted which has its own runner.

## File

### `lua/anvil/lang/lua.lua`

<!-- file: lua/anvil/lang/lua.lua -->
```lua
--- Anvil language pack: Lua
--- Neovim plugin and configuration development
---@type AnvilLangPack
local M = {
  name = "lua",
  filetypes = { "lua" },

  treesitter = { "lua", "luadoc", "luap" },

  lsp = {
    server = "lua_ls",
    settings = {
      Lua = {
        runtime = { version = "LuaJIT" },
        workspace = { checkThirdParty = false },
        completion = {
          callSnippet = "Replace",
          keywordSnippet = "Replace",
        },
        hint = {
          enable = true,
          setType = true,
          paramName = "All",
          paramType = true,
        },
        diagnostics = {
          disable = { "missing-fields", "incomplete-signature-doc" },
        },
        format = { enable = false }, -- stylua handles formatting
        telemetry = { enable = false },
      },
    },
  },

  formatter = {
    tool = "stylua",
  },

  linter = {
    tool = "selene",
  },

  tasks = {
    {
      name = "Lua: Run current file",
      cmd = { "luajit", vim.fn.expand("%:p") },
      lang = "lua",
      filetypes = { "lua" },
    },
    {
      name = "Lua: Run tests (plenary)",
      cmd = {
        "nvim", "--headless", "-u", "tests/minimal_init.lua",
        "-c", "PlenaryBustedDirectory tests/unit",
      },
      lang = "lua",
      filetypes = { "lua" },
    },
  },

  ai = {
    system_prompt = "This is a Neovim Lua project. Use LuaJIT / Lua 5.1 syntax. "
      .. "Use vim.* API for Neovim integration. Follow LuaLS type annotations "
      .. "(---@param, ---@return, ---@class). Use stylua formatting conventions.",
    file_patterns = { ".luarc.json", "stylua.toml", "selene.toml" },
    conventions = "snake_case for functions and variables, PascalCase for classes. "
      .. "Every module returns a table M. Every public function has LuaLS annotations.",
  },

  keys = {
    {
      mode = "n",
      lhs = "<leader>lr",
      rhs = function()
        vim.cmd("source %")
        vim.notify("Sourced: " .. vim.fn.expand("%:t"), vim.log.levels.INFO)
      end,
      desc = "Lua: Source current file",
    },
  },

  plugins = {
    -- lazydev.nvim and luvit-meta are in plugins/lsp.lua (shared, not lang-specific)
    -- They are listed here for documentation completeness but loaded globally
  },
}

return M
```
