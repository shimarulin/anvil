# Anvil — Language Engine

The language engine is the heart of Anvil's "language-first" philosophy. It scans, registers, and aggregates language packs — single-file Lua modules that declaratively describe everything a language needs: LSP, treesitter, formatter, linter, DAP, test runner, tasks, AI context, voice commands, keymaps, and extra plugins.

## Architecture

```text
lua/anvil/lang/
├── init.lua          # Registry + aggregation engine
├── _template.lua     # Language pack contract (type definitions)
├── rust.lua          # Rust pack
├── go.lua            # Go pack
├── python.lua        # Python pack
├── typescript.lua    # TypeScript pack
├── lua.lua           # Lua pack
├── c.lua             # C/C++ pack
├── bash.lua          # Bash pack
├── json.lua          # JSON pack
├── markdown.lua      # Markdown pack
├── docker.lua        # Docker pack
├── html.lua          # HTML/CSS pack
├── sql.lua           # SQL pack
├── zig.lua           # Zig pack
├── nix.lua           # Nix pack
├── proto.lua         # Protobuf pack
└── terraform.lua     # Terraform pack
```

## How It Works

```text
┌─────────────────────────────────────────────────────────────┐
│                    LANGUAGE ENGINE                           │
│                                                             │
│  1. lang.setup(enabled_list)                                │
│     ├── Build source list (priority order):                 │
│     │   1. lua/anvil/lang/*.lua        (built-in)           │
│     │   2. lua/anvil-community/lang/*  (community plugins)  │
│     │   3. config.lang_pack_dirs       (extra directories)  │
│     │   4. lua/user/lang/*.lua         (user overrides)     │
│     ├── Scan each source directory                          │
│     ├── Higher-priority source overrides lower for same name│
│     ├── require() each file → get AnvilLangPack table       │
│     ├── Filter by enabled_list (nil = all)                  │
│     └── Store in registry with _source metadata             │
│                                                             │
│  2. Aggregation functions (called by plugins/*.lua)         │
│     ├── treesitter_ensure_installed()  → string[]           │
│     ├── lsp_servers()        → table<server, settings>      │
│     ├── mason_ensure_installed()       → string[]           │
│     ├── formatters_by_ft()   → table<ft, formatter[]>       │
│     ├── linters_by_ft()      → table<ft, linter[]>          │
│     ├── dap_configurations() → table<adapter, config>       │
│     ├── neotest_adapters()   → table[]                      │
│     ├── tasks()              → AnvilLangTask[]              │
│     ├── extra_plugins()      → LazyPluginSpec[]             │
│     └── ai_context()         → table                        │
│                                                             │
│  3. Per-buffer functions                                    │
│     ├── current()        → pack for current buffer filetype │
│     ├── apply_keys(bufnr) → set language-specific keymaps   │
│     └── ai_context()     → AI context for current language  │
└─────────────────────────────────────────────────────────────┘
```

## Dependency Rules

```text
lang/init.lua    → core/logger, core/events (optional)
lang/<name>.lua  → NOTHING (pure data, no side effects)
```

Language packs are pure data tables. They never call `require()` at the top level (except for returning the table). All plugin requires happen lazily inside functions or are handled by the engine.

## Language Pack Contract

Every language pack implements the `AnvilLangPack` interface defined in `_template.lua`. The contract is strict: the engine relies on the shape of this table for all aggregation.

### Key Concepts

| Field       | Required | Description |
|-------------|----------|-------------|
| `name`      | ✓ | Unique identifier (`"rust"`, `"python"`, etc.) |
| `filetypes` | ✓ | Vim filetypes this pack handles |
| `lsp`       | ✓ | LSP server configuration |
| `treesitter`| ✓ | Treesitter parsers to install |
| `formatter` | ✓ | Formatting tool configuration |
| `linter`    | — | Linting tool (nil if linting is via LSP) |
| `dap`       | — | Debug adapter configuration |
| `test`      | — | Test framework configuration |
| `tasks`     | — | Build/run tasks for overseer |
| `ai`        | — | AI context for this language |
| `voice_commands` | — | Language-specific voice commands |
| `keys`      | — | Language-specific keybindings |
| `plugins`   | — | Additional plugin specs |

### Special Flags

| Flag | Where | Purpose |
|------|-------|---------|
| `managed_by_plugin` | `lsp` | Skip lspconfig registration (plugin manages LSP) |
| `managed_by_lsp` | `formatter` | Skip conform registration (LSP formats) |
| `extra_servers` | `lsp` | Additional LSP servers (dual LSP, e.g. Python) |
| `chain` | `formatter` | Ordered formatter chain (e.g. Go: goimports → gofumpt) |
| `format_on_save` | `formatter` | Disable format-on-save for this language |

## Aggregation Flow

```text
plugins/lsp.lua (LazySpec)
│
├── mason-tool-installer opts:
│   └── lang.mason_ensure_installed()
│       Iterates all packs → collects:
│       - lsp.server (unless managed_by_plugin)
│       - lsp.extra_servers[].server
│       - formatter.tool
│       - formatter.chain items
│       - linter.tool
│       - dap.adapter
│
├── lspconfig config:
│   └── editor/lsp.setup()
│       └── lang.lsp_servers()
│           Iterates all packs → for each:
│           - Skip if managed_by_plugin
│           - Return { server_name = settings }
│           - Also register extra_servers
│
├── treesitter opts:
│   └── editor/treesitter.opts()
│       └── lang.treesitter_ensure_installed()
│           Iterates all packs → collects treesitter[]
│
├── conform opts:
│   └── editor/format.opts()
│       └── lang.formatters_by_ft()
│           Iterates all packs → for each filetype:
│           - Skip if managed_by_lsp
│           - Use chain if present, else { tool }
│
├── nvim-lint config:
│   └── editor/lint.setup()
│       └── lang.linters_by_ft()
│           Iterates all packs → { ft = { linter } }
│
├── nvim-dap config:
│   └── editor/dap.setup()
│       └── lang.dap_configurations()
│
├── neotest config:
│   └── editor/test.build_adapters()
│       └── lang.neotest_adapters() (adapter specs)
│
└── overseer config:
    └── workflow/tasks.register_lang_tasks()
        └── lang.tasks()
```

### `lua/anvil/lang/init.lua`

Language engine — registry, multi-source scanning, and all aggregation functions.

<!-- file: lua/anvil/lang/init.lua -->
```lua
--- Anvil language engine
--- Registry, scanning, and aggregation of language packs
--- Supports multiple pack sources: built-in, community, user
--- Depends on: core/logger (optional), core/events (optional)
---@class AnvilLangEngine
local M = {}

---@type table<string, AnvilLangPack>
M._registry = {}

---@type string[]
M._enabled = {}

---@type string[]
M._available = {}

---@type table<string, string>
M._ft_map = {}

--- Pack source directories in priority order (lowest first, highest last wins)
---@type { name: string, path: string }[]
M._sources = {}

--- Build the list of pack source directories
---@return { name: string, path: string }[]
local function build_sources()
  local sources = {}
  local config_dir = vim.fn.stdpath("config")

  -- 1. Built-in packs (lowest priority)
  sources[#sources + 1] = {
    name = "builtin",
    path = config_dir .. "/lua/anvil/lang",
  }

  -- 2. Community / external packs from runtimepath
  local rtp_dirs = vim.api.nvim_get_runtime_file("lua/anvil-community/lang", true)
  for _, dir in ipairs(rtp_dirs) do
    sources[#sources + 1] = {
      name = "community",
      path = dir,
    }
  end

  -- 3. Extra directories from config
  local config_ok, config = pcall(require, "anvil.config")
  if config_ok then
    local cfg = config.get()
    if cfg.lang_pack_dirs then
      for _, dir in ipairs(cfg.lang_pack_dirs) do
        local expanded = vim.fn.expand(dir)
        if vim.fn.isdirectory(expanded) == 1 then
          sources[#sources + 1] = {
            name = "extra",
            path = expanded,
          }
        end
      end
    end
  end

  -- 4. User packs (highest priority)
  local user_lang_dir = config_dir .. "/lua/user/lang"
  if vim.fn.isdirectory(user_lang_dir) == 1 then
    sources[#sources + 1] = {
      name = "user",
      path = user_lang_dir,
    }
  end

  return sources
end

--- Scan a directory for language pack files
---@param dir string directory path
---@return table<string, string> name → file path
local function scan_dir(dir)
  local packs = {}
  if vim.fn.isdirectory(dir) ~= 1 then return packs end

  local files = vim.fn.glob(dir .. "/*.lua", false, true)
  for _, file in ipairs(files) do
    local name = vim.fn.fnamemodify(file, ":t:r")
    if name ~= "init" and not name:match("^_") then
      packs[name] = file
    end
  end

  return packs
end

--- Load a language pack from a file path
---@param name string pack name
---@param file string file path
---@param source_name string source identifier
---@return AnvilLangPack|nil
local function load_pack(name, file, source_name)
  local pack = nil

  if source_name == "builtin" then
    local ok, result = pcall(require, "anvil.lang." .. name)
    if ok and type(result) == "table" and result.name then
      pack = result
    end
  elseif source_name == "community" then
    local ok, result = pcall(require, "anvil-community.lang." .. name)
    if ok and type(result) == "table" and result.name then
      pack = result
    end
  elseif source_name == "user" then
    local ok, result = pcall(require, "user.lang." .. name)
    if ok and type(result) == "table" and result.name then
      pack = result
    end
  else
    local ok, result = pcall(dofile, file)
    if ok and type(result) == "table" and result.name then
      pack = result
    end
  end

  if pack then
    pack._source = source_name
  end

  return pack
end

--- Scan and register language packs from all sources
---@param enabled_langs? string[] list of language names to enable (nil = all)
function M.setup(enabled_langs)
  M._registry = {}
  M._enabled = {}
  M._available = {}
  M._ft_map = {}
  M._sources = build_sources()

  -- Collect all available packs from all sources
  -- Lower-priority sources are scanned first; higher-priority override
  local all_packs = {} ---@type table<string, { file: string, source: string }>

  for _, source in ipairs(M._sources) do
    local packs = scan_dir(source.path)
    for name, file in pairs(packs) do
      all_packs[name] = { file = file, source = source.name }
    end
  end

  -- Build available list
  for name, _ in pairs(all_packs) do
    M._available[#M._available + 1] = name
  end
  table.sort(M._available)

  -- Load enabled packs
  for name, info in pairs(all_packs) do
    local is_enabled = true
    if enabled_langs then
      is_enabled = vim.tbl_contains(enabled_langs, name)
    end

    if is_enabled then
      local pack = load_pack(name, info.file, info.source)
      if pack then
        M._registry[name] = pack
        M._enabled[#M._enabled + 1] = name

        -- Build filetype → pack mapping
        if pack.filetypes then
          for _, ft in ipairs(pack.filetypes) do
            M._ft_map[ft] = name
          end
        end
      else
        local logger_ok, logger = pcall(require, "anvil.core.logger")
        if logger_ok then
          logger.warn("Lang: failed to load pack '%s' from %s", name, info.source)
        end
      end
    end
  end

  table.sort(M._enabled)

  local logger_ok, logger = pcall(require, "anvil.core.logger")
  if logger_ok then
    local source_counts = {}
    for _, name in ipairs(M._enabled) do
      local pack = M._registry[name]
      if pack and pack._source then
        source_counts[pack._source] = (source_counts[pack._source] or 0) + 1
      end
    end
    local parts = {}
    for source, count in pairs(source_counts) do
      parts[#parts + 1] = source .. ":" .. count
    end
    logger.info(
      "Lang: %d packs enabled out of %d available (%s)",
      #M._enabled, #M._available, table.concat(parts, ", ")
    )
  end

  local events_ok, events = pcall(require, "anvil.core.events")
  if events_ok then
    events.emit("lang:ready", {
      enabled = M._enabled,
      available = M._available,
    })
  end
end

--- Get a language pack by name
---@param name string
---@return AnvilLangPack?
function M.get(name)
  return M._registry[name]
end

--- Get the language pack for the current buffer's filetype
---@return AnvilLangPack?
function M.current()
  local ft = vim.bo.filetype
  local name = M._ft_map[ft]
  if name then return M._registry[name] end
  return nil
end

--- Get list of enabled language names
---@return string[]
function M.enabled()
  return vim.deepcopy(M._enabled)
end

--- Get list of all available language names
---@return string[]
function M.available()
  return vim.deepcopy(M._available)
end

--- Get pack source info
---@param name string
---@return string|nil source name ("builtin", "community", "user", "extra")
function M.source(name)
  local pack = M._registry[name]
  return pack and pack._source or nil
end

--- Aggregate treesitter parsers from all enabled packs
---@return string[]
function M.treesitter_ensure_installed()
  local parsers = {}
  local seen = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.treesitter then
      for _, parser in ipairs(pack.treesitter) do
        if not seen[parser] then
          seen[parser] = true
          parsers[#parsers + 1] = parser
        end
      end
    end
  end
  return parsers
end

--- Aggregate LSP server configurations from all enabled packs
---@return table<string, table>
function M.lsp_servers()
  local servers = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if not pack or not pack.lsp then goto continue end

    if not pack.lsp.managed_by_plugin then
      servers[pack.lsp.server] = {
        settings = pack.lsp.settings or {},
      }
      if pack.lsp.on_attach then
        servers[pack.lsp.server].on_attach = pack.lsp.on_attach
      end
    end

    if pack.lsp.extra_servers then
      for _, extra in ipairs(pack.lsp.extra_servers) do
        local extra_opts = { settings = extra.settings or {} }
        if extra.on_attach then
          extra_opts.on_attach = extra.on_attach
        end
        servers[extra.server] = extra_opts
      end
    end

    ::continue::
  end
  return servers
end

--- Aggregate Mason tools to install from all enabled packs
---@return string[]
function M.mason_ensure_installed()
  local tools = {}
  local seen = {}

  local function add(tool)
    if tool and tool ~= "" and not seen[tool] then
      seen[tool] = true
      tools[#tools + 1] = tool
    end
  end

  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if not pack then goto continue end

    if pack.lsp then
      if not pack.lsp.managed_by_plugin then
        add(pack.lsp.server)
      end
      if pack.lsp.extra_servers then
        for _, extra in ipairs(pack.lsp.extra_servers) do
          add(extra.server)
        end
      end
    end

    if pack.formatter then
      add(pack.formatter.tool)
      if pack.formatter.chain then
        for _, fmt in ipairs(pack.formatter.chain) do
          add(fmt)
        end
      end
    end

    if pack.linter then
      add(pack.linter.tool)
    end

    if pack.dap and pack.dap.dependencies then
      for _, dep in ipairs(pack.dap.dependencies) do
        add(dep)
      end
    end

    ::continue::
  end

  table.sort(tools)
  return tools
end

--- Aggregate formatters by filetype for conform.nvim
---@return table<string, string[]>
function M.formatters_by_ft()
  local result = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if not pack or not pack.formatter then goto continue end
    if pack.formatter.managed_by_lsp then goto continue end

    local formatters = pack.formatter.chain
      or { pack.formatter.tool }

    for _, ft in ipairs(pack.filetypes) do
      result[ft] = formatters
    end

    ::continue::
  end
  return result
end

--- Aggregate linters by filetype for nvim-lint
---@return table<string, string[]>
function M.linters_by_ft()
  local result = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if not pack or not pack.linter then goto continue end

    for _, ft in ipairs(pack.filetypes) do
      result[ft] = { pack.linter.tool }
    end

    ::continue::
  end
  return result
end

--- Aggregate DAP configurations from all enabled packs
---@return table<string, table>
function M.dap_configurations()
  local configs = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if not pack or not pack.dap then goto continue end

    configs[pack.dap.adapter] = {
      adapter = pack.dap.adapter_config,
      configurations = pack.dap.configurations,
      filetypes = pack.dap.filetypes or pack.filetypes,
    }

    ::continue::
  end
  return configs
end

--- Get neotest adapter specs
---@return { adapter: string, config: table }[]
function M.neotest_adapters()
  local adapters = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.test then
      adapters[#adapters + 1] = {
        adapter = pack.test.adapter,
        config = pack.test.config or {},
      }
    end
  end
  return adapters
end

--- Aggregate tasks from all enabled packs
---@return AnvilLangTask[]
function M.tasks()
  local all_tasks = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.tasks then
      for _, task in ipairs(pack.tasks) do
        all_tasks[#all_tasks + 1] = task
      end
    end
  end
  return all_tasks
end

--- Aggregate extra plugin specs from all enabled packs
---@return LazyPluginSpec[]
function M.extra_plugins()
  local plugins = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.plugins then
      for _, spec in ipairs(pack.plugins) do
        plugins[#plugins + 1] = spec
      end
    end
  end
  return plugins
end

--- Get AI context for the current buffer's language
---@return AnvilLangAI?
function M.ai_context()
  local pack = M.current()
  if pack and pack.ai then return pack.ai end
  return nil
end

--- Apply language-specific keymaps to a buffer
---@param bufnr number
function M.apply_keys(bufnr)
  local pack = M.current()
  if not pack or not pack.keys then return end
  for _, key in ipairs(pack.keys) do
    vim.keymap.set(key.mode, key.lhs, key.rhs, {
      buffer = bufnr,
      desc = key.desc,
    })
  end
end

--- Show info about a specific language pack
---@param name string
function M.info(name)
  local pack = M._registry[name]
  if not pack then
    vim.notify("Language pack not found: " .. name, vim.log.levels.WARN)
    return
  end

  local lines = {
    "╭─── " .. pack.name .. " (" .. (pack._source or "unknown") .. ") ───╮",
    "│ Filetypes:  " .. table.concat(pack.filetypes, ", "),
    "│ LSP:        " .. pack.lsp.server
      .. (pack.lsp.managed_by_plugin and " (managed by plugin)" or ""),
  }

  if pack.lsp.extra_servers then
    for _, extra in ipairs(pack.lsp.extra_servers) do
      lines[#lines + 1] = "│ LSP extra:  " .. extra.server
    end
  end

  lines[#lines + 1] = "│ Treesitter: " .. table.concat(pack.treesitter, ", ")
  lines[#lines + 1] = "│ Formatter:  " .. pack.formatter.tool
    .. (pack.formatter.managed_by_lsp and " (via LSP)" or "")
    .. (pack.formatter.chain
      and (" [chain: " .. table.concat(pack.formatter.chain, " → ") .. "]")
      or "")

  if pack.linter then
    lines[#lines + 1] = "│ Linter:     " .. pack.linter.tool
  end
  if pack.dap then
    lines[#lines + 1] = "│ DAP:        " .. pack.dap.adapter
  end
  if pack.test then
    lines[#lines + 1] = "│ Test:       " .. pack.test.adapter
  end
  if pack.tasks then
    lines[#lines + 1] = "│ Tasks:      " .. #pack.tasks
  end
  if pack.ai then
    lines[#lines + 1] = "│ AI context: ✓"
  end
  if pack.voice_commands then
    lines[#lines + 1] = "│ Voice:      " .. #pack.voice_commands .. " commands"
  end
  if pack.keys then
    lines[#lines + 1] = "│ Keymaps:    " .. #pack.keys
  end
  if pack.plugins then
    lines[#lines + 1] = "│ Plugins:    " .. #pack.plugins
  end

  lines[#lines + 1] = "│ Source:     " .. (pack._source or "unknown")
  lines[#lines + 1] = "╰" .. string.rep("─", #lines[1] - 4) .. "╯"

  vim.notify(
    table.concat(lines, "\n"),
    vim.log.levels.INFO,
    { title = "Anvil Lang" }
  )
end

return M
```

## External Language Packs

```text
┌─────────────────────────────────────────────────────────────┐
│  PRIORITY (last wins)                                       │
│                                                             │
│  1. Built-in      lua/anvil/lang/*.lua                      │
│     └── Shipped with Anvil                                  │
│                                                             │
│  2. Community      lua/anvil-community/lang/*.lua            │
│     └── From runtimepath (lazy.nvim plugins)                │
│     └── Does NOT override built-in (unless same name)       │
│                                                             │
│  3. Extra dirs     config.lang_pack_dirs                    │
│     └── User-specified additional directories               │
│                                                             │
│  4. User           lua/user/lang/*.lua                      │
│     └── Always overrides (highest priority)                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

Three ways to add a language without modifying Anvil:

1. **File in `lua/user/lang/`** — the simplest, for personal use
2. **lazy.nvim plugin** — for distributing a single language (`anvil-lang-elixir`)
3. **Community collection** — for a collection of languages (`anvil-community-langs`)

All three methods use the same `AnvilLangPack` contract, all three automatically integrate with Mason, LSP, treesitter, conform, nvim-lint, DAP, neotest, overseer, and voice commands.

### Community Language Pack — as a lazy.nvim plugin

External language packages are distributed as regular lazy.nvim plugins. The plugin simply places files in `lua/anvil-community/lang/`.

Example structure of the `anvil-community-langs` plugin:

```text
anvil-community-langs/
├── lua/
│   └── anvil-community/
│       └── lang/
│           ├── elixir.lua
│           ├── haskell.lua
│           ├── kotlin.lua
│           ├── swift.lua
│           └── zig.lua
└── README.md
```

### User Override of Built-in Package

If a user wants to modify a built-in package (e.g., Rust), they create a file with the same name in `lua/user/lang/`:

#### `lua/user/lang/rust.lua`

Example: the user wants to disable clippy and add their own tasks.

```lua
--- User override for Rust language pack
--- Strategy: extend the built-in pack (require + modify)
--- To completely replace, just return a new AnvilLangPack table.

local base = require("anvil.lang.rust")

-- Override: disable clippy, use plain cargo check
base.lsp.settings["rust-analyzer"].check.command = "check"

-- Add custom tasks
base.tasks[#base.tasks + 1] = {
  name = "Rust: Bench",
  cmd = "cargo bench",
  lang = "rust",
  filetypes = { "rust" },
}

base.tasks[#base.tasks + 1] = {
  name = "Rust: Publish (dry-run)",
  cmd = "cargo publish --dry-run",
  lang = "rust",
  filetypes = { "rust" },
}

-- Add voice commands for Rust
base.voice_commands = {
  {
    phrases = {
      en = { "cargo build", "build rust" },
      ru = { "собери раст", "карго билд" },

    action = function() vim.cmd("OverseerRun cargo build") end,
    desc = "Cargo build",

  {
    phrases = {
      en = { "cargo test", "test rust" },
      ru = { "тестируй раст", "карго тест" },
    },
    action = function() vim.cmd("OverseerRun cargo test") end,
    desc = "Cargo test",
  },
}

return base
```
