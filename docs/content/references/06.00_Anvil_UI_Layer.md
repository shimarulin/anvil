# Anvil — UI Layer

Theme, statusline, bufferline, file explorer, dashboard, notifications,
and zen mode. The UI layer uses a **strategy pattern** to adapt to the
underlying framework: NvChad native UI, AstroNvim native UI, or standalone
plugins.

## Architecture

```
lua/anvil/ui/
├── init.lua              # UI subsystem — strategy detection
├── theme.lua             # Colorscheme registry (multi-theme support)
├── statusline.lua        # Lualine configuration (standalone)
├── bufferline.lua        # Bufferline configuration (standalone)
├── explorer.lua          # Neo-tree configuration (standalone)
├── dashboard.lua         # Alpha dashboard (standalone)
├── notifications.lua     # Noice + nvim-notify
├── zen.lua               # Zen / focus mode
└── strategies/
    ├── standalone.lua    # Full UI: lualine + bufferline + neo-tree + alpha
    ├── nvchad.lua        # NvChad native: base46 + nvchad/ui + nvim-tree
    └── astronvim.lua     # AstroNvim native: astroui (future)

lua/plugins/
└── ui.lua                # UI plugin specs (delegates to strategy)
```

## Strategy Pattern

The UI layer detects which framework (if any) is active and selects the
appropriate strategy:

```
┌─────────────────────────────────────────────────────────┐
│                    anvil.ui.init                        │
│                                                         │
│  detect_strategy()                                      │
│    ├─ NvChad detected?  → strategies/nvchad.lua         │
│    ├─ AstroNvim detected? → strategies/astronvim.lua    │
│    └─ Neither?          → strategies/standalone.lua     │
│                                                         │
│  Each strategy returns LazyPluginSpec[] that are         │
│  merged into plugins/ui.lua                             │
└─────────────────────────────────────────────────────────┘
```

| Strategy   | Statusline     | Bufferline    | Explorer   | Dashboard | Theme         |
|------------|----------------|---------------|------------|-----------|---------------|
| standalone | lualine        | bufferline    | neo-tree   | alpha     | theme.lua registry |
| nvchad     | nvchad/ui      | tabufline     | nvim-tree  | nvdash    | base46        |
| astronvim  | astroui/heirline | astroui     | neo-tree   | alpha     | astroui       |

**Key principle:** when running on top of NvChad or AstroNvim, Anvil does NOT
replace the framework's native UI. It only adds what the framework doesn't
provide (noice, zen-mode, indent guides, etc.).

## UI Strategy Detection

### `lua/anvil/ui/init.lua`

<!-- file: lua/anvil/ui/init.lua -->
```lua
--- Anvil UI subsystem
--- Detects framework and selects UI strategy
---@class AnvilUI
local M = {}

--- Detect which UI strategy to use
--- Can be overridden via config: ui.strategy = "standalone"|"nvchad"|"astronvim"
---@return "nvchad"|"astronvim"|"standalone"
function M.detect_strategy()
  -- Check for user override first
  local config_ok, config = pcall(require, "anvil.config")
  if config_ok then
    local cfg = config.get()
    if cfg.ui and cfg.ui.strategy and cfg.ui.strategy ~= "auto" then
      return cfg.ui.strategy
    end
  end

  -- Auto-detect
  if pcall(require, "nvchad.ui") and pcall(require, "base46") then
    return "nvchad"
  end

  if pcall(require, "astroui") then
    return "astronvim"
  end

  return "standalone"
end

--- Get the active strategy module
---@return table module with specs() function
function M.strategy()
  local name = M.detect_strategy()
  local ok, strategy = pcall(require, "anvil.ui.strategies." .. name)
  if ok then
    return strategy
  end
  -- Fallback to standalone
  return require("anvil.ui.strategies.standalone")
end

return M
```

```lua
---@alias AnvilThemeName "catppuccin"|"tokyonight"|"rose-pine"|"kanagawa"|"gruvbox-material"

--- Theme registry: each entry provides plugin spec + opts
---@type table<AnvilThemeName, { plugin: string, opts: fun(): table, name?: string }>
M.registry = {
  catppuccin = {
    plugin = "catppuccin/nvim",
    name   = "catppuccin",
    opts = function()
      return {
        flavour = "mocha",
        background = { light = "latte", dark = "mocha" },

        },
        integrations = {
          cmp           = true,
          gitsigns      = true,

          telescope     = { enabled = true },
          flash         = true,
          harpoon       = true,
          mason         = true,
          neotest       = true,
          notify        = true,
          which_key     = true,
          mini          = { enabled = true },
          native_lsp    = {
            enabled = true,
            virtual_text = {
              errors      = { "italic" },
              hints       = { "italic" },
              warnings    = { "italic" },
              information = { "italic" },
            },
            underlines = {
              errors      = { "underline" },
              hints       = { "underline" },
              warnings    = { "underline" },
              information = { "underline" },
            },
          },
          dap      = true,
          dap_ui   = true,
          diffview = true,
        },
      }
    end,
  },

  tokyonight = {
    plugin = "folke/tokyonight.nvim",
    opts = function()
      return {
        style = "night",
        transparent = false,
        terminal_colors = true,
        styles = {
          comments  = { italic = true },
          keywords  = { bold = true },
        },
        sidebars = { "qf", "help", "neo-tree", "terminal" },
      }
    end,
  },

  ["rose-pine"] = {
    plugin = "rose-pine/neovim",
    name   = "rose-pine",
    opts = function()
      return {
        variant = "auto",
        dark_variant = "main",
        dim_inactive_windows = true,
      }
    end,
  },

  kanagawa = {
    plugin = "rebelot/kanagawa.nvim",
    opts = function()
      return {
        theme = "wave",
        dimInactive = true,
      }
    end,
  },
}

--- Default theme
---@type AnvilThemeName
M.default = "catppuccin"

--- Get the active theme name from config
---@return string
function M.active()
  local config_ok, config = pcall(require, "anvil.config")
  if config_ok then
    local cfg = config.get()
    if cfg.ui and cfg.ui.colorscheme then
      return cfg.ui.colorscheme
    end
  end
  return M.default
end

--- Get plugin spec for the active theme
---@return LazyPluginSpec
function M.spec()
  local theme_name = M.active()
  local theme = M.registry[theme_name]

  if not theme then
    -- Fallback: treat as a plain colorscheme name (user-installed)
    return {
      dir = ".",
      config = function()
        pcall(vim.cmd.colorscheme, theme_name)
      end,
    }
  end

  return {
    theme.plugin,
    name = theme.name or theme_name,
    lazy = false,
    priority = 1000,
    opts = theme.opts(),
    config = function(_, opts)
      local mod_name = theme.name or theme_name
      local ok, mod = pcall(require, mod_name)
      if ok and mod.setup then
        mod.setup(opts)
      end
      vim.cmd.colorscheme(mod_name)
    end,
  }
end

return M
```

```lua
local M = {}

local icons = require("anvil.core.icons")

      lualine_c = {
        {
          "diagnostics",
          symbols = {
            error = icons.diagnostics.error,
            warn  = icons.diagnostics.warn,
            info  = icons.diagnostics.info,
            hint  = icons.diagnostics.hint,
          },
        },
        { "filetype", icon_only = true, separator = "", padding = { left = 1, right = 0 } },
        {
          "filename",
          path = 1,
          symbols = {
            modified = icons.file.modified,
            readonly = icons.file.readonly,
            unnamed  = icons.file.unnamed,
          },
        },
        -- Navic breadcrumbs
        {
          function()
            local navic_ok, navic = pcall(require, "nvim-navic")
            if navic_ok and navic.is_available() then
              return navic.get_location()
            end
            return ""
          end,
          cond = function()
            local navic_ok, navic = pcall(require, "nvim-navic")
            return navic_ok and navic.is_available()
          end,
        },
      },
      lualine_x = {
        -- AI completion status
        {
          function()
            local comp_ok, comp = pcall(require, "anvil.ai.completion")
            if comp_ok and comp._enabled then
              return icons.misc.ai .. "ON"
            end
            return ""
          end,
          color = { fg = "#89b4fa" },
        },
        -- Overseer task status
        { "overseer", label = "", colored = true },
        {
          "diff",
          symbols = {
            added    = icons.git.added,
            modified = icons.git.modified,
            removed  = icons.git.removed,
          },
        },
      },
      lualine_y = {
        { "progress", separator = " ", padding = { left = 1, right = 0 } },
        { "location", padding = { left = 0, right = 1 } },
      },
      lualine_z = {
        function() return os.date("%H:%M") end,
      },
    },
    extensions = { "neo-tree", "lazy", "toggleterm", "trouble", "overseer", "quickfix" },
  }
end
```

```lua
--- NvChad UI strategy
--- When running on top of NvChad, use its native UI components:
---   base46 themes, nvchad/ui statusline, tabufline, nvdash, nvim-tree
--- Anvil only adds what NvChad doesn't provide.
---

---   ✓ Statusline (nvchad/ui)
```

## How Theme Switching Works

```lua
-- In init.lua — set at boot time:
require("anvil").boot({
  ui = { colorscheme = "tokyonight" },
})

-- At runtime — switch temporarily:
:Anvil theme rose-pine

-- Via environment variable (highest priority):
ANVIL_COLORSCHEME=kanagawa nvim
```

When using NvChad, themes are managed by base46 instead:

```lua
-- In chadrc.lua (NvChad native):
M.base46 = { theme = "onedark" }

-- At runtime (NvChad native):
:lua require("nvchad.themes").open()
```

Anvil's theme registry is **not used** under NvChad — base46 handles everything.
