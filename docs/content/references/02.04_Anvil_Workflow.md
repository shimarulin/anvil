# Anvil — Workflow Layer

Task execution, terminal management, project detection, and session
persistence — the operational backbone that ties everything together.

## Architecture

```
lua/anvil/workflow/
├── init.lua        # workflow subsystem setup
├── terminal.lua    # toggleterm configuration + custom terminals
├── tasks.lua       # overseer task runner
├── project.lua     # project detection and management
└── session.lua     # session persistence

lua/plugins/
└── workflow.lua    # all workflow plugin specs
```

### Integration Points

```
┌─────────────────────────────────────────────────────────────┐
│                     Workflow Layer                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  toggleterm ──→ floating / split terminals                  │
│             ──→ custom terminals (node, dev server, btop)   │
│             ──→ used by: AI external tools (aider, goose)   │
│             ──→ used by: lazygit (git layer)                │
│                                                             │
│  overseer   ──→ task runner (build, test, lint, run)        │
│             ──→ tasks from lang packs (cargo build, go test)│
│             ──→ tasks from Makefile, package.json, etc.     │
│             ──→ AI integration (send output → AI chat)      │
│                                                             │
│  project    ──→ auto-detect project root                    │
│             ──→ telescope project picker                    │
│             ──→ auto-chdir on project switch                │
│             ──→ triggers: env.reload(), ai.index_project()  │
│                                                             │
│  persistence──→ auto-save session on exit                   │
│             ──→ restore session on start                    │
│             ──→ per-project sessions                        │
│                                                             │
│  Events:                                                    │
│  project:changed ──→ core/env.reload()                      │
│                  ──→ ai/context.index_project()             │
│                  ──→ overseer discovers new tasks            │
│                  ──→ session auto-loads                      │
└─────────────────────────────────────────────────────────────┘
```

```lua
--- Anvil terminal configuration
--- Toggleterm with custom terminal instances
--- Used by: AI external tools, lazygit, dev servers
---@class AnvilWorkflowTerminal
local M = {}

---@return LazyPluginSpec
function M.spec()
  return {
    "akinsho/toggleterm.nvim",
    version = "*",
    cmd = { "ToggleTerm", "TermExec" },
    opts = {
      size = function(term)
        if term.direction == "horizontal" then
          return 15
        elseif term.direction == "vertical" then
          return math.floor(vim.o.columns * 0.4)
        end
      end,
      open_mapping = [[<C-\>]],
      hide_numbers = true,
      shade_terminals = true,
      shading_factor = 2,
      start_in_insert = true,
      insert_mappings = true,
      terminal_mappings = true,
      persist_size = true,
      persist_mode = true,
      direction = "float",
      close_on_exit = true,
      shell = vim.o.shell,
      auto_scroll = true,
      float_opts = {
        border = "rounded",
        width = function()
          return math.floor(vim.o.columns * 0.85)
        end,
        height = function()
          return math.floor(vim.o.lines * 0.8)
        end,
        winblend = 3,
      },
    },
    config = function(_, opts)
      require("toggleterm").setup(opts)

      local Terminal = require("toggleterm.terminal").Terminal

      -- ─── Node REPL ───
      local node = Terminal:new({
        cmd = "node",
        direction = "float",
        hidden = true,
      })

      -- ─── Dev server (npm run dev) ───
      local dev_server = Terminal:new({
        cmd = "npm run dev",
        direction = "horizontal",
        hidden = true,
        close_on_exit = false,
        on_open = function()
          vim.notify("Dev server started", vim.log.levels.INFO, { title = "Terminal" })
        end,
      })

      -- ─── System monitor ───
      local monitor_cmd = vim.fn.executable("btop") == 1 and "btop" or "top"
      local monitor = Terminal:new({
        cmd = monitor_cmd,
        direction = "float",
        hidden = true,
      })

      -- ─── Python REPL ───
      local python = Terminal:new({
        cmd = (function()
          local venv = os.getenv("VIRTUAL_ENV")
          if venv then return venv .. "/bin/python" end
          return "python3"
        end)(),
        direction = "float",
        hidden = true,
      })

      -- ─── Keymaps for custom terminals ───
      vim.keymap.set("n", "<leader>Tn", function() node:toggle() end,
        { desc = "Terminal: Node REPL" })
      vim.keymap.set("n", "<leader>Td", function() dev_server:toggle() end,
        { desc = "Terminal: Dev server" })
      vim.keymap.set("n", "<leader>Tm", function() monitor:toggle() end,
        { desc = "Terminal: System monitor" })
      vim.keymap.set("n", "<leader>Tp", function() python:toggle() end,
        { desc = "Terminal: Python REPL" })

      -- ─── Expose for AI external tools ───
      -- AI layer creates its own Terminal instances using toggleterm
      -- No coupling needed here
    end,

    keys = {
      { [[<C-\>]], desc = "Toggle terminal (float)" },
      { "<leader>Tf", "<cmd>ToggleTerm direction=float<CR>",      desc = "Terminal: Float" },
      { "<leader>Th", "<cmd>ToggleTerm direction=horizontal<CR>", desc = "Terminal: Horizontal" },
      { "<leader>Tv", "<cmd>ToggleTerm direction=vertical<CR>",   desc = "Terminal: Vertical" },
      { "<leader>T1", "<cmd>1ToggleTerm<CR>",                     desc = "Terminal: #1" },
      { "<leader>T2", "<cmd>2ToggleTerm<CR>",                     desc = "Terminal: #2" },
      { "<leader>T3", "<cmd>3ToggleTerm<CR>",                     desc = "Terminal: #3" },
    },
  }
end

return M
```

```lua
--- Anvil task runner (overseer.nvim)
--- Discovers tasks from: lang packs, Makefile, package.json, etc.
--- Integrates with AI for output analysis
---@class AnvilWorkflowTasks
local M = {}

---@return LazyPluginSpec
function M.spec()
  return {
    "stevearc/overseer.nvim",
    cmd = {
      "OverseerRun",
      "OverseerToggle",
      "OverseerBuild",
      "OverseerTaskAction",
      "OverseerInfo",
    },
    opts = {
      strategy = "toggleterm",
      templates = { "builtin" },

      task_list = {
        direction = "bottom",
        min_height = 15,
        max_height = 25,
        default_detail = 1,
        bindings = {
          ["?"]     = "ShowHelp",
          ["g?"]    = "ShowHelp",
          ["<CR>"]  = "RunAction",
          ["<C-e>"] = "Edit",
          ["o"]     = "Open",
          ["<C-v>"] = "OpenVsplit",
          ["<C-s>"] = "OpenSplit",
          ["<C-f>"] = "OpenFloat",
          ["<C-q>"] = "OpenQuickFix",
          ["p"]     = "TogglePreview",
          ["<C-l>"] = "IncreaseDetail",
          ["<C-h>"] = "DecreaseDetail",
          ["L"]     = "IncreaseAllDetail",
          ["H"]     = "DecreaseAllDetail",
          ["["]     = "DecreaseWidth",
          ["]"]     = "IncreaseWidth",
          ["{"]     = "PrevTask",
          ["}"]     = "NextTask",
          ["<C-k>"] = "ScrollOutputUp",
          ["<C-j>"] = "ScrollOutputDown",
          ["q"]     = "Close",
        },
      },

      -- Auto-detect success/failure
      auto_detect_success_color = true,

      -- Form for task parameters
      form = {
        border = "rounded",
        win_opts = { winblend = 0 },
      },

      -- Confirm before running destructive tasks
      confirm = {
        border = "rounded",
      },

      -- Task output
      task_win = {
        border = "rounded",
      },
    },

    config = function(_, opts)
      local overseer = require("overseer")
      overseer.setup(opts)

      -- ─── Register tasks from language packs ───
      local lang_ok, lang = pcall(require, "anvil.lang")
      if lang_ok then
        local tasks = lang.tasks()
        for _, task in ipairs(tasks) do
          overseer.register_template({
            name = string.format("[%s] %s", task.lang, task.name),
            builder = function()
              return {
                cmd = task.cmd,
                cwd = vim.fn.getcwd(),
                components = {
                  { "on_output_quickfix", open = false },
                  "default",
                },
              }
            end,
            condition = {
              filetype = task.filetypes,
            },
          })
        end
      end
    end,

    keys = {
      { "<leader>oo", "<cmd>OverseerToggle<CR>",     desc = "Overseer: Toggle task list" },
      { "<leader>or", "<cmd>OverseerRun<CR>",         desc = "Overseer: Run task" },
      { "<leader>ob", "<cmd>OverseerBuild<CR>",       desc = "Overseer: Build" },
      { "<leader>oa", "<cmd>OverseerTaskAction<CR>",  desc = "Overseer: Task action" },
      { "<leader>oI", "<cmd>OverseerInfo<CR>",        desc = "Overseer: Info" },

      -- ─── Send task output to AI ───
      { "<leader>oi",
        function()
          local overseer = require("overseer")
          local tasks = overseer.list_tasks({ recent_first = true })
          if #tasks == 0 then
            vim.notify("No tasks found", vim.log.levels.WARN)
            return
          end

          local task = tasks[1]
          local output = ""

          -- Get output from task buffer
          if task.strategy and task.strategy.bufnr then
            local bufnr = task.strategy.bufnr
            if vim.api.nvim_buf_is_valid(bufnr) then
              local lines = vim.api.nvim_buf_get_lines(bufnr, 0, -1, false)
              output = table.concat(lines, "\n")
            end
          end

          if output == "" then
            vim.notify("No output from task", vim.log.levels.WARN)
            return
          end

          -- Truncate if too long
          if #output > 5000 then
            output = "... (truncated)\n" .. output:sub(-5000)
          end

          -- Send to AI chat
          vim.cmd("CodeCompanionChat")
          vim.defer_fn(function()
            local cc_ok, cc = pcall(require, "codecompanion")
            if not cc_ok then return end
            local chat = cc.last_chat()
            if chat then
              chat:add_message({
                role = "user",
                content = string.format(
                  "Task '%s' (status: %s) output:\n\n```\n%s\n```\n\nAnalyze and help fix any issues.",
                  task.name,
                  task.status,
                  output
                ),
              })
              chat:submit()
            end
          end, 500)
        end,
        desc = "Overseer: Send output → AI" },
    },
  }
end

return M
```

```lua
--- Anvil project detection and management
--- Auto-detects project root, provides telescope picker
---@class AnvilWorkflowProject
local M = {}

---@return LazyPluginSpec
function M.spec()
  return {
    "ahmedkhalf/project.nvim",
    event = "VeryLazy",
    opts = {
      manual_mode = false,

      -- Detection methods (LSP first, then patterns)
      detection_methods = { "lsp", "pattern" },

      -- Patterns that identify a project root
      patterns = {
        -- VCS
        ".git",

        -- JavaScript / TypeScript
        "package.json",
        "tsconfig.json",
        "jsconfig.json",

        -- Framework configs
        "vite.config.ts",
        "vite.config.js",
        "next.config.js",
        "next.config.mjs",
        "next.config.ts",
        "nuxt.config.ts",
        "svelte.config.js",
        "astro.config.mjs",
        "remix.config.js",

        -- Rust
        "Cargo.toml",

        -- Go
        "go.mod",

        -- Python
        "pyproject.toml",
        "setup.py",
        "setup.cfg",
        "requirements.txt",
        "Pipfile",

        -- General
        "Makefile",
        "CMakeLists.txt",
        ".editorconfig",

        -- Nix
        "flake.nix",
      },

      ignore_lsp = {},

      exclude_dirs = {
        "node_modules/",
        "~/.cargo/",
        "~/.local/",
        "/tmp/",
      },

      show_hidden = false,
      silent_chdir = true,
      scope_chdir = "global",
      datapath = vim.fn.stdpath("data"),
    },

    config = function(_, opts)
      require("project_nvim").setup(opts)

      -- Load telescope extension
      require("telescope").load_extension("projects")

      -- ─── Emit event on project change ───
      vim.api.nvim_create_autocmd("DirChanged", {
        group = vim.api.nvim_create_augroup("AnvilProjectChanged", { clear = true }),
        desc = "Anvil: Handle project change",
        callback = function()
          -- Reload environment
          local env_ok, env = pcall(require, "anvil.core.env")
          if env_ok then env.reload() end

          -- Re-index project for AI (deferred)
          vim.defer_fn(function()
            local ai_ok, ai = pcall(require, "anvil.ai")
            if ai_ok and ai.index_project then
              ai.index_project()
            end
          end, 2000)

          -- Emit event for other modules
          local events_ok, events = pcall(require, "anvil.core.events")
          if events_ok then
            events.emit("project:changed", {
              cwd = vim.fn.getcwd(),
            })
          end
        end,
      })
    end,

    keys = {
      { "<leader>fp", "<cmd>Telescope projects<CR>", desc = "Projects" },
    },
  }
end

return M
```

```lua
--- Anvil session persistence
--- Auto-save and restore sessions per project
---@class AnvilWorkflowSession
local M = {}

---@return LazyPluginSpec
function M.spec()
  return {
    "folke/persistence.nvim",
    event = "BufReadPre",
    opts = {
      dir = vim.fn.expand(vim.fn.stdpath("state") .. "/sessions/"),
      options = {
        "buffers",
        "curdir",
        "tabpages",
        "winsize",
        "help",
        "globals",
        "skiprtp",
      },
      pre_save = function()
        -- Close ephemeral windows before saving
        local ephemeral_ft = {
          "neo-tree", "toggleterm", "trouble", "Trouble",
          "lazy", "mason", "notify", "noice",
          "codecompanion", "OverseerList",
        }
        for _, win in ipairs(vim.api.nvim_list_wins()) do
          local buf = vim.api.nvim_win_get_buf(win)
          local ft = vim.bo[buf].filetype
          if vim.tbl_contains(ephemeral_ft, ft) then
            pcall(vim.api.nvim_win_close, win, true)
          end
        end
      end,
    },
    keys = {
      { "<leader>qs",
        function() require("persistence").load() end,
        desc = "Session: Restore (current dir)" },
      { "<leader>ql",
        function() require("persistence").load({ last = true }) end,
        desc = "Session: Restore last" },
      { "<leader>qd",
        function() require("persistence").stop() end,
        desc = "Session: Stop auto-save" },
    },
  }
end

return M
```

```lua
--- Anvil test runner (neotest)
--- Adapters are provided by language packs
---@class AnvilWorkflowTest
local M = {}

---@return LazyPluginSpec
function M.spec()
  local lang = require("anvil.lang")
  local icons = require("anvil.core.icons")

  -- Collect neotest adapter plugins from lang packs
  local adapter_plugins = lang.neotest_adapters()

  return {
    "nvim-neotest/neotest",
    dependencies = vim.list_extend({
      "nvim-neotest/nvim-nio",
      "nvim-lua/plenary.nvim",
      "antoinemadec/FixCursorHold.nvim",
      "nvim-treesitter/nvim-treesitter",
    }, adapter_plugins),

    cmd = { "Neotest" },

    config = function()
      -- Build adapter list from lang packs
      local adapters = {}
      for _, name in ipairs(lang.enabled()) do
        local pack = lang.get(name)
        if pack and pack.test then
          local ok, adapter = pcall(require, pack.test.adapter)
          if ok then
            table.insert(adapters, adapter(pack.test.config or {}))
          end
        end
      end

      require("neotest").setup({
        adapters = adapters,
        status = {
          virtual_text = true,
          signs = true,
        },
        output = {
          enabled = true,
          open_on_run = "short",
        },
        quickfix = {
          enabled = true,
          open = function()
            vim.cmd("Trouble quickfix")
          end,
        },
        icons = {
          expanded   = icons.ui.fold_open,
          child_prefix  = "",
          child_indent  = "",
          final_child_prefix = "",
          non_collapsible = "",
          collapsed  = icons.ui.fold_closed,
          passed     = icons.test.passed,
          running    = icons.test.running,
          failed     = icons.test.failed,
          unknown    = icons.test.unknown,
          watching   = icons.test.watching,
        },
      })
    end,

    keys = {
      { "<leader>tt",
        function() require("neotest").run.run() end,
        desc = "Test: Run nearest" },
      { "<leader>tT",
        function() require("neotest").run.run(vim.fn.expand("%")) end,
        desc = "Test: Run file" },
      { "<leader>ta",
        function() require("neotest").run.run(vim.fn.getcwd()) end,
        desc = "Test: Run all" },
      { "<leader>ts",
        function() require("neotest").summary.toggle() end,
        desc = "Test: Toggle summary" },
      { "<leader>to",
        function() require("neotest").output.open({ enter = true, auto_close = true }) end,
        desc = "Test: Show output" },
      { "<leader>tO",
        function() require("neotest").output_panel.toggle() end,
        desc = "Test: Toggle output panel" },
      { "<leader>tS",
        function() require("neotest").run.stop() end,
        desc = "Test: Stop" },
      { "<leader>tw",
        function() require("neotest").watch.toggle(vim.fn.expand("%")) end,
        desc = "Test: Watch file" },

      -- ─── Debug test ───
      { "<leader>td",
        function() require("neotest").run.run({ strategy = "dap" }) end,
        desc = "Test: Debug nearest" },

      -- ─── Send failures to AI ───
      { "<leader>tf",
        function()
          local neotest = require("neotest")
          local ctx = require("anvil.ai.context")
          local results = ctx.get_test_results()

          if results == "" then
            vim.notify("No test failures found", vim.log.levels.INFO)
            return
          end

          vim.cmd("CodeCompanionChat")
          vim.defer_fn(function()
            local cc_ok, cc = pcall(require, "codecompanion")
            if not cc_ok then return end
            local chat = cc.last_chat()
            if chat then
              chat:add_message({
                role = "user",
                content = "Analyze and fix these test failures:\n\n" .. results,
              })
              chat:submit()
            end
          end, 500)
        end,
        desc = "Test: Send failures → AI" },
    },
  }
end
```

```lua
local M = {}

---@return LazyPluginSpec[]
function M.specs()
  local icons = require("anvil.core.icons")

        -- ── DAP UI ──
        dapui.setup({
          icons = { expanded = "▾", collapsed = "▸", current_frame = "▸" },
          mappings = {
            expand = { "<CR>", "<2-LeftMouse>" },
            open = "o",
            remove = "d",
            edit = "e",
            repl = "r",
            toggle = "t",
          },
          layouts = {
            {
              elements = {
                { id = "scopes",      size = 0.35 },
                { id = "breakpoints", size = 0.15 },
                { id = "stacks",      size = 0.25 },
                { id = "watches",     size = 0.25 },
              },
              size = 40,
              position = "left",
            },
            {
              elements = {
                { id = "repl",    size = 0.5 },
                { id = "console", size = 0.5 },
              },
              size = 0.25,
              position = "bottom",
            },
          },
          floating = {
            max_height = nil,
            max_width = nil,
            border = "rounded",
            mappings = { close = { "q", "<Esc>" } },
          },
        })

        -- ── Virtual text ──
        require("nvim-dap-virtual-text").setup({
          enabled = true,
          enabled_commands = true,
          highlight_changed_variables = true,
          highlight_new_as_changed = false,
          show_stop_reason = true,
          commented = false,
          virt_text_pos = "eol",
        })

        -- ── Auto open/close DAP UI ──
        dap.listeners.after.event_initialized["dapui_config"] = function()
          dapui.open()
        end
        dap.listeners.before.event_terminated["dapui_config"] = function()
          dapui.close()
        end
        dap.listeners.before.event_exited["dapui_config"] = function()
          dapui.close()
        end

        -- ── Breakpoint signs ──
        vim.fn.sign_define("DapBreakpoint",
          { text = icons.dap.breakpoint, texthl = "DapBreakpoint" })
        vim.fn.sign_define("DapBreakpointCondition",
          { text = icons.dap.breakpoint_condition, texthl = "DapBreakpointCondition" })
        vim.fn.sign_define("DapLogPoint",
          { text = icons.dap.logpoint, texthl = "DapLogPoint" })
        vim.fn.sign_define("DapStopped",
          { text = icons.dap.stopped, texthl = "DapStopped", linehl = "DapStoppedLine" })
        vim.fn.sign_define("DapBreakpointRejected",
          { text = icons.dap.breakpoint_rejected, texthl = "DapBreakpointRejected" })

        -- ── Load DAP configurations from language packs ──
        for _, name in ipairs(lang.enabled()) do
          local pack = lang.get(name)
          if pack and pack.dap then
            -- Adapters are typically set up by mason-nvim-dap
            -- or language-specific plugins (e.g., dap-vscode-js)
            -- Here we register the configurations
            for _, ft in ipairs(pack.filetypes) do
              dap.configurations[ft] = vim.list_extend(
                dap.configurations[ft] or {},
                pack.dap.configurations
              )
            end
          end
        end
      end,

      keys = {
        { "<leader>db",
          function() require("dap").toggle_breakpoint() end,
          desc = "Debug: Toggle breakpoint" },
        { "<leader>dB",
          function()
            require("dap").set_breakpoint(vim.fn.input("Breakpoint condition: "))
          end,
          desc = "Debug: Conditional breakpoint" },
        { "<leader>dl",
          function()
            require("dap").set_breakpoint(nil, nil, vim.fn.input("Log point message: "))
          end,
          desc = "Debug: Log point" },
        { "<leader>dc",
          function() require("dap").continue() end,
          desc = "Debug: Continue" },
        { "<leader>di",
          function() require("dap").step_into() end,
          desc = "Debug: Step into" },
        { "<leader>do",
          function() require("dap").step_over() end,
          desc = "Debug: Step over" },
        { "<leader>dO",
          function() require("dap").step_out() end,
          desc = "Debug: Step out" },
        { "<leader>dr",
          function() require("dap").repl.toggle() end,
          desc = "Debug: Toggle REPL" },
        { "<leader>ds",
          function() require("dap").session() end,
          desc = "Debug: Session" },
        { "<leader>dt",
          function() require("dap").terminate() end,
          desc = "Debug: Terminate" },
        { "<leader>du",
          function() require("dapui").toggle() end,
          desc = "Debug: Toggle DAP UI" },
        { "<leader>de",
          function() require("dapui").eval() end,
          mode = { "n", "v" },
          desc = "Debug: Eval expression" },
```

## Workflow Examples

### Run a task and send output to AI

```
1. <leader>or       → Overseer: pick a task (e.g., "cargo build")
2. Task runs in toggleterm
3. Build fails with errors
4. <leader>oi       → Sends task output to AI chat
5. AI analyzes errors and suggests fixes
```

### Test-driven development with AI

```
1. Write a test (or <leader>ag to generate tests via AI)
2. <leader>tt       → Run nearest test
3. Test fails
4. <leader>tf       → Send failure to AI
5. AI analyzes and provides fix
6. Apply fix
7. <leader>tt       → Re-run test
8. <leader>tw       → Watch mode for continuous feedback
```

### Debug a failing test

```
1. <leader>tt       → Run test, see it fail
2. <leader>db       → Set breakpoint at suspicious line
3. <leader>td       → Debug nearest test (runs with DAP)
4. DAP UI opens automatically
5. <F10>/<F11>      → Step through code
6. <leader>de       → Eval expression under cursor
7. Find the bug
8. <leader>dt       → Terminate debug session
9. Fix the code
10. <leader>tt      → Verify fix
```

### Project switching

```
1. <leader>fp       → Telescope project picker
2. Select project   → Neovim changes directory
3. Automatically:
   - .env reloaded (new API keys, etc.)
   - Project re-indexed for AI
   - Overseer discovers new tasks
   - Session can be restored (<leader>qs)
```
