# Anvil — Lang Pack: Lua

Complete Lua development environment focused on Neovim plugin development
and configuration: lua_ls with full Neovim API awareness via lazydev,
stylua formatting, selene linting, and Neovim-specific debugging.

## Overview

| Component | Tool | Notes |
|---|---|---|
| LSP | lua_ls | With Neovim runtime, lazy.nvim types |
| Types | lazydev.nvim | Neovim API, vim.uv, plugin types |
| Treesitter | `lua`, `luadoc`, `luap` | Syntax + doc comments + patterns |
| Formatter | stylua | Via conform.nvim |
| Linter | selene | Via nvim-lint |
| DAP | nlua / local-lua-debugger | Neovim Lua and standalone Lua |
| Test | busted (via overseer) | No neotest adapter needed |

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                      Lua Lang Pack                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  lua_ls (LSP) ──→ completion, diagnostics, hover, goto     │
│               ──→ type checking (annotations-based)         │
│               ──→ inlay hints                               │
│               ──→ workspace: Neovim runtime + plugins       │
│                                                             │
│  lazydev.nvim ──→ vim.* API types and completion            │
│               ──→ vim.uv (libuv) types                     │
│               ──→ lazy.nvim plugin spec types               │
│               ──→ installed plugin library types            │
│               ──→ project-local type stubs                  │
│                                                             │
│  conform      ──→ stylua (formatting)                       │
│                                                             │
│  nvim-lint    ──→ selene (linting)                          │
│                                                             │
│  DAP          ──→ nlua (debug Neovim Lua in-process)        │
│               ──→ local-lua-debugger (standalone Lua)       │
│                                                             │
│  overseer     ──→ busted, make test, luacheck, etc.         │
│                                                             │
│  AI context   ──→ Neovim Lua-specific system prompt         │
│               ──→ Lua/Neovim-specific review rules          │
└─────────────────────────────────────────────────────────────┘
```

### Neovim Lua vs Standalone Lua

This lang pack is optimized for **Neovim Lua** — writing Neovim
configurations and plugins. It includes full Neovim API type support
via lazydev.nvim. For standalone Lua (e.g., game scripting with LÖVE,
OpenResty, etc.), the same LSP and formatter work but the library
paths would differ.

## Language Pack

### `lua/anvil/lang/lua.lua`

```lua
--- Anvil language pack: Lua
--- Focused on Neovim plugin development and configuration
---@type AnvilLangPack
return {
  name = "lua",
  filetypes = { "lua" },

  -- ══════════════════════════════════════
  -- LSP
  -- ══════════════════════════════════════
  lsp = {
    server = "lua_ls",

    settings = {
      Lua = {
        -- ─── Runtime ───
        runtime = {
          version = "LuaJIT",
          -- Path for require resolution
          path = {
            "lua/?.lua",
            "lua/?/init.lua",
          },
        },

        -- ─── Workspace ───
        workspace = {
          -- Disable third-party checking (lazydev handles this)
          checkThirdParty = false,
          -- Library paths are managed by lazydev.nvim
        },

        -- ─── Completion ───
        completion = {
          callSnippet = "Replace",
          keywordSnippet = "Replace",
          displayContext = 5,
          postfix = ".",
        },

        -- ─── Diagnostics ───
        diagnostics = {
          globals = { "vim" },
          disable = {
            "missing-fields",    -- too noisy with plugin opts
            "incomplete-signature-doc",
          },
          unusedLocalExclude = { "_*" }, -- allow _unused pattern
          neededFileStatus = {
            ["codestyle-check"] = "Any",
          },
        },

        -- ─── Inlay hints ───
        hint = {
          enable = true,
          setType = true,
          paramType = true,
          paramName = "Literal",
          semicolon = "Disable",
          arrayIndex = "Disable",
        },

        -- ─── Type checking ───
        type = {
          castNumberToInteger = true,
          weakUnionCheck = true,
        },

        -- ─── Formatting ───
        -- Disabled — we use stylua via conform
        format = {
          enable = false,
        },

        -- ─── Telemetry ───
        telemetry = {
          enable = false,
        },

        -- ─── Doc ───
        doc = {
          privateName = { "^_" },
        },
      },
    },

    on_attach = function(client, bufnr)
      -- Disable formatting — stylua via conform handles this
      client.server_capabilities.documentFormattingProvider = false
      client.server_capabilities.documentRangeFormattingProvider = false
    end,
  },

  -- ══════════════════════════════════════
  -- Treesitter
  -- ══════════════════════════════════════
  treesitter = { "lua", "luadoc", "luap" },

  -- ══════════════════════════════════════
  -- Formatting
  -- stylua: opinionated Lua formatter
  -- ══════════════════════════════════════
  formatter = {
    tool = "stylua",
    format_on_save = true,
  },

  -- ══════════════════════════════════════
  -- Linting
  -- selene: modern Lua linter
  -- ══════════════════════════════════════
  linter = {
    tool = "selene",
  },

  -- ══════════════════════════════════════
  -- Debug
  -- ══════════════════════════════════════
  dap = {
    adapter = "local-lua-debugger-vscode", -- mason install name

    configurations = {
      -- Debug Neovim Lua (in-process via nlua/osv)
      {
        type = "nlua",
        request = "attach",
        name = "Attach to Neovim",
        -- Requires: lua require('osv').launch({ port = 8086 })
        -- in the target Neovim instance
        host = "127.0.0.1",
        port = function()
          return tonumber(vim.fn.input("Port: ", "8086"))
        end,
      },
      -- Debug standalone Lua script
      {
        type = "local-lua",
        request = "launch",
        name = "Launch Lua file",
        program = {
          lua = "lua5.1", -- or luajit
          file = "${file}",
        },
        cwd = "${workspaceFolder}",
      },
      -- Debug busted tests
      {
        type = "local-lua",
        request = "launch",
        name = "Launch busted tests",
        program = {
          lua = "lua5.1",
          file = function()
            return vim.fn.input("Test file: ", "spec/", "file")
          end,
        },
        args = { "--verbose" },
        cwd = "${workspaceFolder}",
      },
    },
  },

  -- ══════════════════════════════════════
  -- Testing
  -- No well-maintained neotest adapter for busted
  -- Tests run via overseer tasks
  -- ══════════════════════════════════════
  test = nil,

  -- ══════════════════════════════════════
  -- Tasks (overseer)
  -- ══════════════════════════════════════
  tasks = {
    -- Neovim plugin testing
    { name = "make test",                cmd = "make test" },
    { name = "busted",                   cmd = "busted" },
    { name = "busted verbose",           cmd = "busted --verbose" },
    { name = "busted (file)",            cmd = { "busted", "--verbose", "${file}" } },
    { name = "vusted",                   cmd = "vusted" },
    { name = "vusted (file)",            cmd = { "vusted", "${file}" } },

    -- Neovim headless test
    { name = "nvim test (minimal)",      cmd = "nvim --headless -u tests/minimal_init.lua -c 'PlenaryBustedDirectory tests/ {minimal_init = \"tests/minimal_init.lua\"}'" },

    -- Linting
    { name = "selene",                   cmd = "selene ." },
    { name = "selene (file)",            cmd = { "selene", "${file}" } },
    { name = "luacheck",                 cmd = "luacheck ." },
    { name = "luacheck (file)",          cmd = { "luacheck", "${file}" } },

    -- Formatting
    { name = "stylua check",            cmd = "stylua --check ." },
    { name = "stylua format",           cmd = "stylua ." },

    -- Misc
    { name = "lua run",                  cmd = { "lua", "${file}" } },
    { name = "luajit run",              cmd = { "luajit", "${file}" } },
  },

  -- ══════════════════════════════════════
  -- AI Context
  -- ══════════════════════════════════════
  ai = {
    system_prompt = [[
You are a Lua and Neovim expert. Follow these principles:

For Neovim Lua:
- Use vim.api for Neovim API calls
- Use vim.keymap.set() for keymaps (not vim.api.nvim_set_keymap)
- Use vim.fn for Vimscript function calls
- Use vim.opt / vim.bo / vim.wo for options (not vim.cmd("set ..."))
- Use vim.schedule() or vim.defer_fn() for deferred execution
- Use vim.notify() for user messages (not print())
- Use pcall() for error handling when calling potentially failing functions
- Use ---@type, ---@class, ---@param, ---@return annotations for all public APIs
- Use ---@diagnostic disable-next-line for intentional suppressions
- Follow lazy.nvim plugin spec format for plugin configurations
- Use vim.uv (libuv) for async I/O, timers, filesystem operations
- Prefer vim.tbl_extend, vim.tbl_deep_extend for table merging
- Use vim.validate() for argument validation in public functions
- Prefer vim.iter() for functional iteration (Neovim 0.10+)
- Use vim.lpeg for pattern matching when regex is insufficient

For general Lua:
- Local variables by default (never pollute global scope)
- Use string methods (s:find, s:match) over string library functions
- Tables are the primary data structure — use them idiomatically
- Metatables for OOP patterns (__index, __newindex, __call)
- Avoid global state; use module-local state with M pattern
- Return module table at end of file: return M
]],

    review_rules = {
      "Check for global variable leaks — all variables should be local",
      "Verify ---@type annotations on all public functions and parameters",
      "Check for proper error handling — pcall/xpcall where functions can fail",
      "Verify vim.api usage — prefer vim.keymap.set over nvim_set_keymap",
      "Check for vim.cmd usage — prefer Lua API equivalents where they exist",
      "Verify lazy loading — plugins should use event, cmd, ft, or keys for lazy loading",
      "Check for proper use of vim.schedule in callbacks that modify buffer",
      "Verify module pattern — file returns M table, no side effects on require",
      "Check for unnecessary vim.fn calls — prefer Lua equivalents",
      "Verify autocmd cleanup — groups should be used, clear = true",
      "Check for proper buffer/window locality — use vim.bo/vim.wo not vim.o where appropriate",
      "Verify no deprecated API usage (check :help deprecated)",
    },

    patterns = {
      "*.lua",
      ".luarc.json",
      ".luarc.jsonc",
      "stylua.toml",
      ".stylua.toml",
      "selene.toml",
      ".luacheckrc",
    },
  },

  -- ══════════════════════════════════════
  -- Language-specific keybindings
  -- ══════════════════════════════════════
  keys = {
    -- ─── Run ───
    { key = "<leader>rr", cmd = function()
        local file = vim.fn.expand("%:p")
        vim.cmd("TermExec cmd='lua " .. file .. "'")
      end,
      desc = "Lua: Run file" },

    { key = "<leader>rR", cmd = function()
        local file = vim.fn.expand("%:p")
        vim.cmd("TermExec cmd='luajit " .. file .. "'")
      end,
      desc = "Lua: Run file (LuaJIT)" },

    -- ─── Source (Neovim Lua) ───
    { key = "<leader>rx", cmd = "<cmd>source %<CR>",
      desc = "Lua: Source current file" },

    { key = "<leader>rl", cmd = function()
        -- Execute current line as Lua
        local line = vim.api.nvim_get_current_line()
        local ok, err = pcall(loadstring(line))
        if ok then
          vim.notify("Executed: " .. line, vim.log.levels.INFO)
        else
          vim.notify("Error: " .. tostring(err), vim.log.levels.ERROR)
        end
      end,
      desc = "Lua: Execute current line" },

    { key = "<leader>re", cmd = function()
        -- Execute visual selection as Lua
        local start_line = vim.fn.line("'<")
        local end_line = vim.fn.line("'>")
        local lines = vim.api.nvim_buf_get_lines(0, start_line - 1, end_line, false)
        local code = table.concat(lines, "\n")
        local ok, err = pcall(loadstring(code))
        if ok then
          vim.notify("Executed selection", vim.log.levels.INFO)
        else
          vim.notify("Error: " .. tostring(err), vim.log.levels.ERROR)
        end
      end,
      desc = "Lua: Execute selection",
      mode = "v" },

    -- ─── Debug (Neovim) ───
    { key = "<leader>rd", cmd = function()
        -- Start OSV debug server in current Neovim instance
        local ok, osv = pcall(require, "osv")
        if ok then
          osv.launch({ port = 8086 })
          vim.notify("OSV debug server started on port 8086", vim.log.levels.INFO)
        else
          vim.notify("osv not available — install jbyuki/one-small-step-for-vimkind", vim.log.levels.WARN)
        end
      end,
      desc = "Lua: Start Neovim debug server" },

    -- ─── Testing ───
    { key = "<leader>rt", cmd = function()
        vim.cmd("TermExec cmd='busted --verbose'")
      end,
      desc = "Lua: Run busted tests" },

    { key = "<leader>rT", cmd = function()
        local file = vim.fn.expand("%:p")
        vim.cmd("TermExec cmd='busted --verbose " .. file .. "'")
      end,
      desc = "Lua: Run busted (file)" },

    -- ─── Inspect ───
    { key = "<leader>rI", cmd = function()
        -- Inspect object under cursor
        local word = vim.fn.expand("<cword>")
        local ok, result = pcall(loadstring("return vim.inspect(" .. word .. ")"))
        if ok and result then
          -- Show in floating window
          local lines = vim.split(result, "\n")
          local buf = vim.api.nvim_create_buf(false, true)
          vim.api.nvim_buf_set_lines(buf, 0, -1, false, lines)
          vim.bo[buf].filetype = "lua"
          local width = math.min(80, vim.o.columns - 4)
          local height = math.min(#lines, 30)
          vim.api.nvim_open_win(buf, true, {
            relative = "cursor",
            row = 1,
            col = 0,
            width = width,
            height = height,
            style = "minimal",
            border = "rounded",
          })
          vim.keymap.set("n", "q", "<cmd>close<CR>", { buffer = buf })
        else
          vim.notify("Cannot inspect: " .. word, vim.log.levels.WARN)
        end
      end,
      desc = "Lua: Inspect value" },
  },

  -- ══════════════════════════════════════
  -- Extra plugins
  -- ══════════════════════════════════════
  plugins = {
    -- ─── lazydev.nvim ───
    -- Provides Neovim API types, vim.uv types, plugin types to lua_ls
    {
      "folke/lazydev.nvim",
      ft = "lua",
      dependencies = {
        -- luvit types (vim.uv)
        { "Bilal2453/luvit-meta", lazy = true },
      },
      opts = {
        library = {
          -- Load luvit types when vim.uv is found
          { path = "luvit-meta/library", words = { "vim%.uv" } },
          -- Load lazy.nvim types
          { path = "lazy.nvim",          words = { "LazySpec", "LazyPluginSpec" } },
          -- Load Anvil types from project
          { path = vim.fn.stdpath("config") .. "/lua" },
        },
        -- Enable type checking integration
        integrations = {
          lspconfig = true,
          cmp = true,
        },
      },
    },

    -- ─── one-small-step-for-vimkind ───
    -- Debug Neovim Lua in-process (DAP adapter)
    {
      "jbyuki/one-small-step-for-vimkind",
      ft = "lua",
      config = function()
        local dap = require("dap")

        -- Register nlua adapter
        dap.adapters.nlua = function(callback, config)
          callback({
            type = "server",
            host = config.host or "127.0.0.1",
            port = config.port or 8086,
          })
        end
      end,
    },
  },
}
```

## Debugging Neovim Lua

Debugging Neovim Lua requires a special setup because the code runs
inside the Neovim process itself.

### How it works

```
┌─────────────────────┐         ┌─────────────────────┐
│  Neovim Instance A  │         │  Neovim Instance B   │
│  (being debugged)   │◄───────►│  (debugger UI)       │
│                     │  TCP    │                      │
│  1. :lua            │  8086   │  2. DAP attach       │
│     require('osv')  │         │     type = "nlua"    │
│     .launch({       │         │     port = 8086      │
│       port = 8086   │         │                      │
│     })              │         │  3. Set breakpoints  │
│                     │         │  4. Trigger code      │
│  5. Hits breakpoint │         │  5. DAP UI shows     │
│                     │         │     variables, stack  │
└─────────────────────┘         └─────────────────────┘
```

### Step-by-step

```
1. In the Neovim instance you want to debug:
   <leader>rd     → starts OSV debug server on port 8086

2. In your development Neovim (with DAP):
   <leader>db     → set breakpoint in the Lua file
   <leader>dc     → continue → select "Attach to Neovim"
   → Enter port: 8086

3. In the debugged Neovim, trigger the code
   (e.g., run a command, open a file, etc.)

4. Breakpoint hits → DAP UI shows variables, call stack

5. <F10>/<F11>    → step through code
   <leader>de     → eval expression
   <leader>dt     → terminate
```

### Single-instance debugging

For simpler cases, you can debug within the same Neovim instance:

```lua
-- In command line:
:lua require('osv').run_this()
-- This runs the current buffer with the debugger attached
```

## Workflow Examples

### Workflow: Develop a Neovim plugin

```
1. Create plugin structure:
   my-plugin/
   ├── lua/
   │   └── my-plugin/
   │       ├── init.lua
   │       └── utils.lua
   ├── tests/
   │   ├── minimal_init.lua
   │   └── my-plugin/
   │       └── init_spec.lua
   ├── stylua.toml
   ├── selene.toml
   └── Makefile

2. Open init.lua
   → lua_ls starts with lazydev.nvim
   → Full vim.* API completion
   → Type annotations for lazy.nvim specs

3. Write code with annotations:
   ---@param opts MyPluginOpts
   ---@return MyPlugin
   function M.setup(opts)
     vim.validate({ opts = { opts, "table", true } })
     ...
   end

4. <leader>rx     → source file to test in current Neovim
5. <leader>rl     → execute current line to test a snippet
6. <leader>rI     → inspect a value under cursor

7. Format on save → stylua runs automatically
8. Selene diagnostics appear inline
```

### Workflow: Debug a Neovim plugin

```
1. Open plugin source in Neovim A (development)
2. <leader>db     → set breakpoint
3. Open Neovim B (target):
   <leader>rd     → start debug server (port 8086)
4. Back in Neovim A:
   <leader>dc     → "Attach to Neovim" → port 8086
5. In Neovim B: trigger the plugin code
6. Breakpoint hits in Neovim A → inspect variables
```

### Workflow: AI-assisted Lua/Neovim development

```
1. <leader>ac     → open AI chat
2. /project       → add project context
3. Ask: "Create a telescope extension for browsing git stashes"
   → AI knows Neovim Lua conventions from system_prompt
   → Uses vim.api, proper annotations, module pattern
   → Returns M table, uses pcall for error handling

4. <leader>ar     → AI code review
   → Checks for global leaks, missing annotations, deprecated API
   → Uses Lua-specific review_rules

5. <leader>rx     → source the file to test immediately
```
