# Anvil — Lang: Markdown

Markdown language pack with preview and linting.

## Summary

| Feature | Tool |
|---|---|
| LSP | `marksman` |
| Treesitter | `markdown`, `markdown_inline` |
| Formatter | `prettierd` |
| Linter | `markdownlint` |
| DAP | — |
| Test | — |

## Design Decisions

- **marksman** — Markdown LSP with wiki-link support, document symbols, and go-to-definition for headings/links.
- **prettierd** — formats Markdown tables, wraps long lines, normalizes list markers.
- **markdownlint** — catches common Markdown issues (inconsistent heading levels, trailing spaces, etc.). Configured via `.markdownlint.json` or `.markdownlint.yaml` in project root.
- **render-markdown.nvim** — already included in AI plugin specs for CodeCompanion chat. Also renders Markdown buffers with icons, code blocks, and bullet points.
- `format_on_save = false` — Markdown formatting can be disruptive when writing prose. Users can format manually with `<leader>lf`.

## File

### `lua/anvil/lang/markdown.lua`

<!-- file: lua/anvil/lang/markdown.lua -->
```lua
--- Anvil language pack: Markdown
--- Documentation and prose with preview and linting
---@type AnvilLangPack
local M = {
  name = "markdown",
  filetypes = { "markdown", "mdx" },

  treesitter = { "markdown", "markdown_inline" },

  lsp = {
    server = "marksman",
  },

  formatter = {
    tool = "prettierd",
    format_on_save = false, -- Markdown formatting can be disruptive
  },

  linter = {
    tool = "markdownlint",
  },

  tasks = {
    {
      name = "Markdown: Preview (glow)",
      cmd = { "glow", vim.fn.expand("%:p") },
      lang = "markdown",
      filetypes = { "markdown" },
    },
  },

  ai = {
    system_prompt = "This is a Markdown document. "
      .. "Use proper heading hierarchy (h1 → h2 → h3). "
      .. "Use fenced code blocks with language tags. "
      .. "Use reference-style links for repeated URLs.",
    file_patterns = { "README.md", "CHANGELOG.md", "CONTRIBUTING.md", "docs/" },
    conventions = "ATX-style headings (# not ===). "
      .. "One sentence per line for better diffs. "
      .. "Blank line before and after headings, lists, and code blocks.",
  },

  keys = {
    {
      mode = "n",
      lhs = "<leader>lp",
      rhs = function()
        if vim.fn.executable("glow") == 1 then
          vim.cmd("terminal glow " .. vim.fn.expand("%:p"))
        else
          vim.notify("glow not installed. Install: go install github.com/charmbracelet/glow@latest", vim.log.levels.WARN)
        end
      end,
      desc = "Markdown: Preview (glow)",
    },
    {
      mode = "n",
      lhs = "<leader>lt",
      rhs = function()
        -- Toggle conceallevel for Markdown
        local cl = vim.wo.conceallevel
        vim.wo.conceallevel = cl == 0 and 2 or 0
        vim.notify("Conceallevel: " .. vim.wo.conceallevel, vim.log.levels.INFO)
      end,
      desc = "Markdown: Toggle conceal",
    },
  },
}

return M
```

## Keymaps

| Key | Mode | Description |
|---|---|---|
| `<leader>lp` | n | Preview with glow |
| `<leader>lt` | n | Toggle conceal level |
