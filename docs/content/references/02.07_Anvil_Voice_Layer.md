# Anvil — Voice Layer

Voice input subsystem: speech-to-text, command recognition, AI-powered interpretation, and hands-free editor control. Disabled by default — activates on demand via `<F3>` (push-to-talk) or `<leader>vv` (toggle continuous listening).

## Architecture

```text
┌─────────────────────────────────────────────────────────────────┐
│                      ANVIL VOICE LAYER                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────────┐  ┌──────────────┐  ┌───────────────────┐     │
│  │  STT Engine   │  │   Command    │  │  AI Interpreter   │     │
│  │  (whisper     │──▶│   Registry   │──▶│  (slot: fast)     │     │
│  │   .cpp)       │  │  (direct     │  │  Natural language  │     │
│  │              │  │   matching)  │  │  → action JSON     │     │
│  └──────┬───────┘  └──────┬───────┘  └────────┬──────────┘     │
│         │                 │                    │                 │
│         │  ┌──────────────┘                    │                 │
│         │  │                                   │                 │
│  ┌──────▼──▼─────┐              ┌───────────────────┐           │
│  │    Action      │              │    Feedback        │           │
│  │    Executor    │              │  (statusline 🎤,   │           │
│  │               │              │   notifications)   │           │
│  └──────────────┘              └───────────────────┘           │
│                                                                 │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │                       Event Bus                           │   │
│  │  voice:started │ voice:stopped │ voice:recognized         │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## Design Decisions

**Variant C — AI-powered interpretation** (ADR-030). Instead of building a rigid grammar parser, voice commands flow through two stages: (1) direct phrase matching against a command registry, and (2) AI fallback via the `fast` slot for anything unmatched. This leverages Anvil's existing AI infrastructure to understand natural language, tolerate STT errors, and handle synonyms without maintaining complex grammars.

**whisper.cpp as default STT engine.** Runs locally, supports 99 languages, no cloud dependency. The `small` model (244 MB) provides the best balance of accuracy and speed for short voice commands on CPU. Larger models (`turbo`, `large-v3`) available for users with GPU or higher accuracy needs.

**Multi-language support.** Whisper auto-detects the spoken language. Users can fix a language via configuration for faster recognition. Commands are registered with phrases in multiple languages — the system matches against all of them.

**External process via libuv.** The STT engine runs as a separate process communicating via stdout pipe. This never blocks Neovim's main loop. Managed through `vim.uv` (libuv), consistent with how Anvil handles other external tools.

**Off by default** (same pattern as minuet-ai, ADR-022). Voice input is entirely opt-in. No microphone access, no background process until the user explicitly activates it.

**Provider-style engine abstraction.** The STT engine uses a strategy pattern (like `ui/strategies/`), allowing future backends (Vosk for ultra-low-latency, cloud STT for maximum accuracy) without changing the command layer.

## Whisper and Russian Language

Whisper from OpenAI is one of the best models for Russian. Russian is in the top-10 languages by recognition quality.

### Word Error Rate (WER) on Fleurs test

| Model | Size | WER Russian | WER English | RAM | Speed (CPU) |
|-------|------|-------------|-------------|-----|-------------|
| tiny | 39 MB | ~18% | ~8% | ~1 GB | Realtime |
| base | 74 MB | ~13% | ~5% | ~1 GB | Realtime |
| small | 244 MB | ~8% | ~3% | ~2 GB | ~2x realtime |
| medium | 769 MB | ~5% | ~3% | ~5 GB | ~5x realtime |
| large-v3 | 1.5 GB | ~3% | ~2% | ~10 GB | ~10x realtime |
| turbo | 809 MB | ~4% | ~2% | ~6 GB | ~3x realtime |

For voice commands (short phrases, 2-5 words), accuracy is significantly higher than WER on long texts. The `small` or `turbo` model is the optimal choice.

### Key features for Russian

**What works excellently:**
- Recognition of short commands ("открой файл", "следующая вкладка")
- Auto-detection of language (can mix Russian and English)
- Technical terms in English within Russian speech ("открой файл main dot lua")
- Numbers and file names

**What needs attention:**
- Transliteration: "кэмелКейс" may be recognized differently
- Variable names: better to dictate in English ("variable process data")
- Punctuation when dictating code: needs post-processing

## How It Works

### Recognition Pipeline

```text
Microphone
    │
    ▼
whisper.cpp (stream mode)
    │ stdout: recognized text lines
    ▼
engine.lua — parse, detect language, schedule on main loop
    │
    ▼
voice/init.lua — on_recognized(text, lang, confidence)
    │
    ├──▶ commands.lua — try_match()
    │       Fuzzy match against registered phrases
    │       Score ≥ 0.7 → execute action directly
    │       │
    │       └──▶ Action executed ✓
    │
    └──▶ (no match)
            │
            ▼
        interpreter.lua — interpret()
            Send to AI (slot: fast):
              system prompt with action schema
              + recognized text
              + current file context
            │
            ▼
        AI returns JSON: {"action": "find_file", "query": "main"}
            │
            ▼
        Execute mapped action ✓
```

### Two-Stage Command Resolution

**Stage 1 — Direct matching.** The command registry holds phrases in multiple languages. Fuzzy string similarity (word overlap + substring matching) tolerates minor STT errors. This stage is instant — no network call.

**Stage 2 — AI interpretation.** When no direct match is found, the recognized text is sent to the AI provider configured for the `fast` slot. A structured system prompt constrains the AI to respond with a JSON action object from a predefined schema. The AI understands context (current file, filetype), synonyms, and partial commands.

This two-stage approach means:
- Common commands execute instantly (no AI latency)
- Unusual or creative phrasing still works (AI handles it)
- New commands can be added to either stage independently

### Why This Works Better Than Grammar Parsing

| Approach | Rigid grammar | AI interpretation |
|----------|---------------|-------------------|
| "open file main" | ✓ | ✓ |
| "show me the main file" | ✗ | ✓ |
| "where is the entry point" | ✗ | ✓ (context-aware) |
| "строка 42" | ✗ (needs per-language grammar) | ✓ |
| "rename this to processData" | ✗ (needs entity extraction) | ✓ |
| STT error: "find fial" | ✗ | ✓ (AI tolerates typos) |

## AI Interpreter (Variant C)

The interpreter sends a structured prompt to the `fast` AI slot:

```text
System: You are a voice command interpreter for Neovim.
        Available actions: { find_file, grep, goto_line, ... }
        Respond with EXACTLY one JSON object.

User:   Voice command (language: ru): "открой файл мейн"
        Current file: src/index.ts
        Filetype: typescript

AI:     {"action": "find_file", "query": "main"}
```

The AI can return any of these action types:

```text
Navigation: find_file, grep, goto_definition, find_references,
```

### Language Configuration

```lua
-- In voice engine setup (or future config/voice.json):
require("anvil.voice.engine").setup({

  -- language = "en",  -- English only (faster)
  -- language = "ru",  -- Russian only (faster)
```

`auto` mode detects the spoken language per utterance. Fixed language mode skips detection and is ~200ms faster per recognition.

### Audio Recording

For push-to-talk mode, the engine records audio using the first available tool:

| Tool | Platform | Notes |
|------|----------|-------|
| `arecord` | Linux (ALSA) | Most common on Linux |
| `sox` | Cross-platform | Install via package manager |
| `ffmpeg` | Cross-platform | Uses AVFoundation on macOS |

Continuous listening mode uses `whisper-cpp-stream` which handles audio capture internally via SDL2.

## Source Code

### `lua/anvil/voice/init.lua`

<!-- lua/anvil/voice/init.lua -->
Entry point — lazy initialization, same pattern as `ai/init.lua`.

```lua
--- Anvil voice input subsystem
--- Lazy-loaded: initializes on first voice command
--- Uses Whisper STT + AI interpretation (slot: fast)
--- Depends on: core/events, core/logger
---@class AnvilVoice
local M = {}

---@type boolean
M._initialized = false

---@type boolean
M._listening = false

--- Ensure voice subsystem is initialized
local function ensure_init()
  if M._initialized then return end
  M._initialized = true

  local engine = require("anvil.voice.engine")
  engine.setup()

  local commands = require("anvil.voice.commands")
  commands.register_defaults()

  local feedback = require("anvil.voice.feedback")
  feedback.setup()

  local logger = require("anvil.core.logger")
  logger.info("Voice subsystem initialized")
end

--- Toggle voice listening on/off
function M.toggle()
  ensure_init()
  M._listening = not M._listening

  local engine = require("anvil.voice.engine")
  if M._listening then
    engine.start()
    require("anvil.core.events").emit("voice:started")
    vim.notify("🎤 Voice: listening...", vim.log.levels.INFO)
  else
    engine.stop()
    require("anvil.core.events").emit("voice:stopped")
    vim.notify("🎤 Voice: stopped", vim.log.levels.INFO)
  end
end

--- Push-to-talk: start listening, stop on key release
--- For use with a held key (e.g. <F3>)
function M.push_to_talk()
  ensure_init()
  local engine = require("anvil.voice.engine")
  engine.start_single()
end

--- Process recognized text (called by engine)
---@param text string recognized speech
---@param lang string detected language ("ru", "en", etc.)
---@param confidence number 0.0-1.0
function M.on_recognized(text, lang, confidence)
  if not text or text == "" then return end

  local logger = require("anvil.core.logger")
  logger.debug("Voice recognized [%s, %.0f%%]: %s", lang, confidence * 100, text)

  require("anvil.core.events").emit("voice:recognized", {
    text = text,
    lang = lang,
    confidence = confidence,
  })

  -- Try direct command match first
  local commands = require("anvil.voice.commands")
  local matched = commands.try_match(text, lang)

  if not matched then
    -- Fallback to AI interpretation
    require("anvil.voice.interpreter").interpret(text, lang)
  end
end

--- Check if voice is currently listening
---@return boolean
function M.is_listening()
  return M._listening
end

--- Register user commands
function M.register_commands()
  local cmd = vim.api.nvim_create_user_command

  cmd("AnvilVoice", function()
    M.toggle()
  end, { desc = "Anvil: Toggle voice input" })

  cmd("AnvilVoicePTT", function()
    M.push_to_talk()
  end, { desc = "Anvil: Push-to-talk" })

  cmd("AnvilVoiceCommands", function()
    require("anvil.voice.commands").show_all()
  end, { desc = "Anvil: Show voice commands" })
end

return M
```

### `lua/anvil/voice/engine.lua`

STT engine: manages the whisper.cpp process.

<!-- lua/anvil/voice/engine.lua -->
```lua
--- Anvil voice STT engine
--- Manages whisper.cpp process for speech-to-text
--- Supports Russian and English (auto-detect or fixed language)
--- Depends on: core/logger, core/cache
---@class AnvilVoiceEngine
local M = {}

local logger = require("anvil.core.logger")
local uv = vim.uv or vim.loop

---@class AnvilVoiceEngineConfig
---@field whisper_bin? string path to whisper.cpp binary (or "whisper-cpp-stream")
---@field model? string path to whisper model file
---@field language? string "ru", "en", "auto" (default: "auto")
---@field device? string audio device (default: system default)
---@field sample_rate? number audio sample rate (default: 16000)
---@field step_ms? number processing step in ms (default: 3000)
---@field keep_ms? number audio context to keep in ms (default: 200)
---@field vad_threshold? number voice activity detection threshold (default: 0.6)
---@field translate? boolean translate to English (default: false)
M._config = {
  whisper_bin = nil,     -- auto-detect
  model = nil,           -- auto-detect
  language = "auto",     -- "auto" detects ru/en automatically
  sample_rate = 16000,
  step_ms = 3000,
  keep_ms = 200,
  vad_threshold = 0.6,
  translate = false,
}

---@type uv_process_t|nil
M._process = nil

---@type uv_pipe_t|nil
M._stdout = nil

--- Setup engine with configuration
---@param opts? AnvilVoiceEngineConfig
function M.setup(opts)
  M._config = vim.tbl_deep_extend("force", M._config, opts or {})

  -- Auto-detect whisper binary
  if not M._config.whisper_bin then
    local candidates = {
      "whisper-cpp-stream",
      "whisper-stream",
      vim.fn.stdpath("data") .. "/whisper.cpp/stream",
      vim.fn.expand("~/.local/bin/whisper-cpp-stream"),
    }
    for _, bin in ipairs(candidates) do
      if vim.fn.executable(bin) == 1 then
        M._config.whisper_bin = bin
        break
      end
    end
  end

  -- Auto-detect model
  if not M._config.model then
    local data_dir = vim.fn.stdpath("data") .. "/whisper-models"
    local model_candidates = {
      data_dir .. "/ggml-small.bin",   -- best for Russian
      data_dir .. "/ggml-base.bin",
      data_dir .. "/ggml-turbo.bin",
      vim.fn.expand("~/.local/share/whisper.cpp/models/ggml-small.bin"),
    }
    for _, model in ipairs(model_candidates) do
      if vim.fn.filereadable(model) == 1 then
        M._config.model = model
        break
      end
    end
  end

  if not M._config.whisper_bin then
    logger.warn("Voice: whisper binary not found. Install whisper.cpp or set path.")
  end
  if not M._config.model then
    logger.warn("Voice: whisper model not found. Run :AnvilVoiceInstall")
  end
end

--- Build command-line arguments for whisper.cpp stream
---@return string[]
function M._build_args()
  local args = {
    "--model", M._config.model,
    "--step", tostring(M._config.step_ms),
    "--keep", tostring(M._config.keep_ms),
    "--vad-thold", tostring(M._config.vad_threshold),
    "--no-timestamps",
    "--print-special", "false",
  }

  -- Language setting
  if M._config.language ~= "auto" then
    table.insert(args, "--language")
    table.insert(args, M._config.language)
  end

  if M._config.translate then
    table.insert(args, "--translate")
  end

  return args
end

--- Start continuous listening
function M.start()
  if M._process then
    logger.debug("Voice: already listening")
    return
  end

  if not M._config.whisper_bin or not M._config.model then
    vim.notify(
      "Voice: whisper not configured. Run :AnvilVoiceInstall",
      vim.log.levels.ERROR
    )
    return
  end

  local stdout = uv.new_pipe(false)
  local stderr = uv.new_pipe(false)
  M._stdout = stdout

  local args = M._build_args()
  logger.debug("Voice: starting %s %s", M._config.whisper_bin, table.concat(args, " "))

  local handle, pid = uv.spawn(M._config.whisper_bin, {
    args = args,
    stdio = { nil, stdout, stderr },
    detached = false,
  }, function(code, signal)
    logger.debug("Voice: process exited (code=%d, signal=%d)", code, signal)
    M._process = nil
    vim.schedule(function()
      require("anvil.core.events").emit("voice:stopped")
    end)
  end)

  if not handle then
    logger.error("Voice: failed to start whisper process")
    return
  end

  M._process = handle
  logger.info("Voice: listening (PID %d, lang=%s)", pid, M._config.language)

  -- Read stdout for recognized text
  local buffer = ""
  stdout:read_start(function(err, data)
    if err then
      logger.error("Voice: read error: %s", err)
      return
    end
    if not data then return end

    buffer = buffer .. data
    -- whisper.cpp stream outputs lines
    while true do
      local newline = buffer:find("\n")
      if not newline then break end
      local line = buffer:sub(1, newline - 1):gsub("^%s+", ""):gsub("%s+$", "")
      buffer = buffer:sub(newline + 1)

      if line ~= "" and not line:match("^%[") then
        vim.schedule(function()
          M._process_line(line)
        end)
      end
    end
  end)

  -- Log stderr
  stderr:read_start(function(err, data)
    if data then
      logger.debug("Voice (stderr): %s", data:gsub("\n$", ""))
    end
  end)
end

--- Process a recognized line from whisper
---@param line string
function M._process_line(line)
  -- whisper.cpp stream format: just the text, possibly with [lang] prefix
  local lang = "auto"
  local text = line

  -- Some whisper builds output language tag
  local detected_lang, rest = line:match("^%[(%a+)%]%s*(.+)$")
  if detected_lang then
    lang = detected_lang
    text = rest
  end

  -- Skip very short or noise
  if #text < 2 then return end

  -- Estimate confidence (whisper.cpp stream doesn't output it directly)
  local confidence = 0.8

  -- Detect language heuristically if whisper didn't report it
  if lang == "auto" then
    lang = M._detect_language(text)
  end

  require("anvil.voice").on_recognized(text, lang, confidence)
end

--- Simple language detection heuristic
---@param text string
---@return string "ru"|"en"
function M._detect_language(text)
  -- Check for Cyrillic characters
  local cyrillic_count = 0
  local latin_count = 0
  for char in text:gmatch(utf8 and "[%z\1-\127\194-\244][\128-\191]*" or ".") do
    local byte = char:byte()
    if byte >= 0xD0 and byte <= 0xD1 then
      cyrillic_count = cyrillic_count + 1
    elseif byte >= 65 and byte <= 122 then
      latin_count = latin_count + 1
    end
  end
  return cyrillic_count > latin_count and "ru" or "en"
end

--- Start single recognition (push-to-talk)
function M.start_single()
  if not M._config.whisper_bin or not M._config.model then
    vim.notify("Voice: not configured", vim.log.levels.ERROR)
    return
  end

  local tmp_wav = vim.fn.tempname() .. ".wav"

  -- Record audio using arecord (Linux) or sox
  local record_cmd
  if vim.fn.executable("arecord") == 1 then
    record_cmd = string.format(
      "arecord -f S16_LE -r %d -c 1 -d 5 %s",
      M._config.sample_rate, tmp_wav
    )
  elseif vim.fn.executable("sox") == 1 then
    record_cmd = string.format(
      "sox -d -r %d -c 1 -b 16 %s trim 0 5",
      M._config.sample_rate, tmp_wav
    )
  elseif vim.fn.executable("ffmpeg") == 1 then
    record_cmd = string.format(
      "ffmpeg -f avfoundation -i :0 -ar %d -ac 1 -t 5 %s -y 2>/dev/null",
      M._config.sample_rate, tmp_wav
    )
  else
    vim.notify(
      "Voice: no audio recorder found (need arecord, sox, or ffmpeg)",
      vim.log.levels.ERROR
    )
    return
  end

  vim.notify("🎤 Listening (5 sec)...", vim.log.levels.INFO)

  vim.fn.jobstart(record_cmd, {
    on_exit = function(_, code)
      if code ~= 0 then
        vim.schedule(function()
          vim.notify("Voice: recording failed", vim.log.levels.ERROR)
        end)
        return
      end

      -- Now transcribe
      local whisper_cmd = string.format(
        "%s -m %s -l %s --no-timestamps -f %s",
        M._config.whisper_bin:gsub("stream$", "main"),
        M._config.model,
        M._config.language,
        tmp_wav
      )

      vim.fn.jobstart(whisper_cmd, {
        stdout_buffered = true,
        on_stdout = function(_, data)
          local text = table.concat(data, " "):gsub("^%s+", ""):gsub("%s+$", "")
          if text ~= "" then
            vim.schedule(function()
              local lang = M._detect_language(text)
              require("anvil.voice").on_recognized(text, lang, 0.85)
            end)
          end
        end,
        on_exit = function()
          vim.fn.delete(tmp_wav)
        end,
      })
    end,
  })
end

--- Stop listening
function M.stop()
  if M._process then
    M._process:kill("sigterm")
    M._process = nil
  end
  if M._stdout then
    M._stdout:read_stop()
    M._stdout:close()
    M._stdout = nil
  end
  logger.debug("Voice: stopped")
end

--- Check if engine is available
---@return boolean available
---@return string? reason
function M.is_available()
  if not M._config.whisper_bin then
    return false, "whisper binary not found"
  end
  if not M._config.model then
```

```lua
--- Try to match recognized text against registered commands
---@param text string recognized speech
---@param lang string "ru" or "en"
---@return boolean matched
function M.try_match(text, lang)
  local normalized = text:lower()
    :gsub("[%.,%!%?]", "")
    :gsub("%s+", " ")
    :gsub("^%s+", "")
    :gsub("%s+$", "")

  local best_match = nil
  local best_score = 0
  local threshold = 0.7  -- minimum similarity for a match

  for _, cmd in ipairs(M._commands) do
    -- Check phrases in detected language first, then all languages
    local langs_to_check = { lang }
    if lang ~= "ru" then table.insert(langs_to_check, "ru") end
    if lang ~= "en" then table.insert(langs_to_check, "en") end

    for _, check_lang in ipairs(langs_to_check) do
      local phrases = cmd.phrases[check_lang]
      if phrases then
        for _, phrase in ipairs(phrases) do
          local score = M._similarity(normalized, phrase:lower())
          if score > best_score and score >= threshold then
            best_score = score
            best_match = cmd
          end
        end
      end
    end
  end

  if best_match then
    local logger = require("anvil.core.logger")
    logger.debug(
      "Voice: matched '%s' → %s (score=%.2f)",
      text, best_match.desc, best_score
    )

    vim.schedule(function()
      local ok, err = pcall(best_match.action)
      if not ok then
        logger.error("Voice: command failed: %s", err)
      end
    end)
    return true
  end

  return false
end

--- String similarity (word overlap + substring matching)
--- Works for both Cyrillic and Latin
---@param s1 string
---@param s2 string
---@return number 0.0-1.0
function M._similarity(s1, s2)
  if s1 == s2 then return 1.0 end

  -- Exact substring match
  if s1:find(s2, 1, true) or s2:find(s1, 1, true) then
    local shorter = math.min(#s1, #s2)
    local longer = math.max(#s1, #s2)
    return shorter / longer
  end

  -- Word-level overlap
  local words1 = {}
  for w in s1:gmatch("%S+") do words1[w] = true end
  local words2 = {}
  for w in s2:gmatch("%S+") do words2[w] = true end

  local common = 0
  local total = 0
  for w in pairs(words1) do
    total = total + 1
    if words2[w] then common = common + 1 end
  end
  for w in pairs(words2) do
    if not words1[w] then total = total + 1 end
  end

  if total == 0 then return 0 end
  return common / total
end

--- Show all registered commands (for :AnvilVoiceCommands)
function M.show_all()
  local by_category = {}
  for _, cmd in ipairs(M._commands) do
    if not by_category[cmd.category] then
      by_category[cmd.category] = {}
    end
    table.insert(by_category[cmd.category], cmd)
  end

  local lines = { "╭─── Anvil Voice Commands ───╮", "" }
  local categories = {}
  for cat in pairs(by_category) do
```

```lua
--- Interpret a voice command using AI
---@param text string recognized speech
---@param lang string detected language
function M.interpret(text, lang)
  local providers = require("anvil.ai.providers")
  local resolved = providers.resolve("fast")

  if not resolved then
    logger.warn("Voice: no AI provider for 'fast' slot — cannot interpret")
    vim.schedule(function()
      vim.notify("🎤 Не понял: " .. text, vim.log.levels.WARN)
    end)
    return
  end

  logger.debug("Voice: AI interpreting '%s' via %s", text, resolved.model.model)

  -- Build request
  local url = resolved.provider.endpoint .. "/chat/completions"
  local body = vim.json.encode({
    model = resolved.model.model,
    messages = {
      { role = "system", content = M._system_prompt },
      {
        role = "user",
        content = string.format(
          "Voice command (language: %s): \"%s\"\n\nCurrent file: %s\nFiletype: %s",
          lang, text,
          vim.fn.expand("%:~:."),
          vim.bo.filetype
        ),
      },
    },
    max_tokens = 200,
    temperature = 0.1,
  })

  -- Async HTTP request via curl
  local response_chunks = {}
  vim.fn.jobstart({
    "curl", "-s", "-X", "POST", url,
    "-H", "Content-Type: application/json",
    "-H", "Authorization: Bearer " .. resolved.provider.api_key,
    "-d", body,
  }, {
    stdout_buffered = true,
    on_stdout = function(_, data)
      if data then
        for _, chunk in ipairs(data) do
          if chunk ~= "" then
            table.insert(response_chunks, chunk)
          end
        end
      end
    end,
    on_exit = function(_, code)
      if code ~= 0 then
        logger.error("Voice: AI request failed (code %d)", code)
        return
      end

      vim.schedule(function()
        local response_text = table.concat(response_chunks, "")
        local ok, response = pcall(vim.json.decode, response_text)
        if not ok then
          logger.error("Voice: failed to parse AI response")
          return
        end

        local content = response.choices
          and response.choices[1]
          and response.choices[1].message
          and response.choices[1].message.content

        if not content then
          logger.error("Voice: empty AI response")
          return
        end

        -- Parse the action JSON
        local action_ok, action = pcall(
          vim.json.decode,
          content:match("{.-}") or "{}"
        )
        if not action_ok or not action.action then
          logger.warn("Voice: AI couldn't interpret: %s", text)
          vim.notify("🎤 Не понял: " .. text, vim.log.levels.WARN)
          return
        end

        logger.info("Voice: AI interpreted '%s' → %s", text, action.action)
        M._execute_action(action)
      end)
    end,
  })
end
```

### `lua/anvil/voice/install.lua`

Dependency installer for whisper.cpp and models.

<!-- lua/anvil/voice/feedback.lua -->
```lua
--- Anvil voice dependency installer
--- Downloads and builds whisper.cpp + Russian-capable model
--- Depends on: core/logger
---@class AnvilVoiceInstall
local M = {}

local logger = require("anvil.core.logger")

--- Data directory for voice models
---@return string
function M.data_dir()
  return vim.fn.stdpath("data") .. "/whisper-models"
end

--- whisper.cpp source directory
---@return string
function M.whisper_dir()
  return vim.fn.stdpath("data") .. "/whisper.cpp"
end

--- Install whisper.cpp and download model
---@param model_size? string "tiny"|"base"|"small"|"medium" (default: "small")
function M.install(model_size)
  model_size = model_size or "small"

  vim.notify(
    "🎤 Installing whisper.cpp + model '" .. model_size .. "'...",
    vim.log.levels.INFO
  )

  local whisper_dir = M.whisper_dir()
  local model_dir = M.data_dir()

  vim.fn.mkdir(model_dir, "p")

  -- Step 1: Clone or update whisper.cpp
  local step1_cmd
  if vim.fn.isdirectory(whisper_dir .. "/.git") == 1 then
    step1_cmd = "cd " .. vim.fn.shellescape(whisper_dir) .. " && git pull"
  else
    step1_cmd = "git clone --depth 1 https://github.com/ggerganov/whisper.cpp "
      .. vim.fn.shellescape(whisper_dir)
  end

  -- Step 2: Build
  local step2_cmd = "cd " .. vim.fn.shellescape(whisper_dir) .. " && make stream"

  -- Step 3: Download model
  local model_url = string.format(
    "https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-%s.bin",
    model_size
  )
  local model_path = model_dir .. "/ggml-" .. model_size .. ".bin"
  local step3_cmd
  if vim.fn.filereadable(model_path) == 1 then
    step3_cmd = "echo 'Model already exists'"
  else
    step3_cmd = string.format(
      "curl -L -o %s %s",
      vim.fn.shellescape(model_path),
      vim.fn.shellescape(model_url)
    )
  end

  -- Step 4: Symlink binary
  local bin_dir = vim.fn.expand("~/.local/bin")
  local step4_cmd = string.format(
    "mkdir -p %s && ln -sf %s/stream %s/whisper-cpp-stream",
    vim.fn.shellescape(bin_dir),
    vim.fn.shellescape(whisper_dir),
    vim.fn.shellescape(bin_dir)
  )

  -- Run all steps sequentially
  local full_cmd = table.concat({
    step1_cmd,
    step2_cmd,
    step3_cmd,
    step4_cmd,
  }, " && ")

  local Terminal = require("toggleterm.terminal").Terminal
  Terminal:new({
    cmd = full_cmd,
    direction = "float",
    close_on_exit = false,
    on_exit = function(_, _, code)
      vim.schedule(function()
        if code == 0 then
          vim.notify(
            "🎤 whisper.cpp installed! Model: " .. model_size
              .. "\nRestart voice with :AnvilVoice",
            vim.log.levels.INFO
          )
          -- Re-setup engine with new paths
          require("anvil.voice.engine").setup()
        else
          vim.notify(
            "🎤 Installation failed. Check the terminal output.",
            vim.log.levels.ERROR
          )
        end
      end)
    end,
  }):toggle()
end

--- Register install command
function M.register_commands()
  vim.api.nvim_create_user_command("AnvilVoiceInstall", function(args)
    local size = args.args ~= "" and args.args or "small"
    M.install(size)
  end, {
    nargs = "?",
    complete = function()
      return { "tiny", "base", "small", "medium", "large-v3", "turbo" }
    end,
    desc = "Anvil: Install whisper.cpp + model for voice input",
  })
end

return M
```

## Integration with Anvil Subsystems

### Event Bus

Voice emits events that any module can subscribe to:

```lua

  local text = args.data.text
  local lang = args.data.lang
  -- custom handling
end)

-- React to voice start/stop
events.on("voice:started", function() ... end)

```

### AI Provider System

Voice interpretation uses the existing slot system (ADR-028):

```text
Slot: fast → openrouter/claude-haiku (default)
Used for: commit messages, error explanations, voice interpretation
```

When the user switches presets (`:AnvilPreset corporate`), voice interpretation automatically uses the corporate provider — no separate configuration needed.

### Language Packs

Voice commands are language-pack-aware. The AI interpreter receives the current filetype, enabling context-sensitive responses:

```text
Voice: "run" (in a Rust file)   → OverseerRun "cargo run"
Voice: "run" (in a Go file)     → OverseerRun "go run ."
Voice: "run" (in a Python file) → OverseerRun "python3 %"
```

## Limitations

| Limitation | Workaround |
|-----------|------------|
| No microphone in SSH sessions | Use push-to-talk with local audio forwarding, or disable voice |
| Background noise triggers false positives | Use push-to-talk mode instead of continuous listening |
| whisper.cpp requires ~1-2 GB RAM | Use `tiny` or `base` model on constrained machines |
| SDL2 required for continuous mode | Push-to-talk works without SDL2 (uses arecord/sox/ffmpeg) |
| AI interpretation adds ~0.5-1s latency | Direct command matching is instant; AI is only the fallback |
| Code dictation is experimental | Use AI chat for complex code input instead |
