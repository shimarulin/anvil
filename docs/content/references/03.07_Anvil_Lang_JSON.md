# Anvil — Lang: JSON

JSON and JSONC language pack with schema validation.

## Summary

| Feature | Tool |
|---|---|
| LSP | `jsonls` (vscode-json-languageserver) |
| Treesitter | `json`, `json5`, `jsonc` |
| Formatter | `prettierd` |
| Linter | — (via LSP schema validation) |
| DAP | — |
| Test | — |

## Design Decisions

- **jsonls** — provides JSON schema validation via SchemaStore. Automatically validates `package.json`, `tsconfig.json`, `.eslintrc`, and hundreds of other files.
- **prettierd** — consistent formatting for JSON files. LSP formatting is disabled for jsonls.
- **JSONC support** — `tsconfig.json` and similar files use JSONC (JSON with comments). Treesitter `jsonc` parser handles this.
- No linter — jsonls provides schema validation and syntax checking.

## File

### `lua/anvil/lang/json.lua`

<!-- file: lua/anvil/lang/json.lua -->
```lua
--- Anvil language pack: JSON
--- JSON and JSONC with schema validation
---@type AnvilLangPack
local M = {
  name = "json",
  filetypes = { "json", "jsonc", "json5" },

  treesitter = { "json", "json5", "jsonc" },

  lsp = {
    server = "jsonls",
    settings = {
      json = {
        schemas = function()
          local ok, schemastore = pcall(require, "schemastore")
          if ok then
            return schemastore.json.schemas()
          end
          return {}
        end,
        validate = { enable = true },
      },
    },
  },

  formatter = {
    tool = "prettierd",
  },

  ai = {
    system_prompt = "This is a JSON configuration file. "
      .. "Ensure valid JSON syntax. Use consistent indentation (2 spaces). "
      .. "For JSONC files (tsconfig.json, etc.), comments are allowed.",
    file_patterns = {
      "package.json", "tsconfig.json", ".eslintrc.json",
      ".prettierrc", "composer.json",
    },
    conventions = "2-space indentation. Keys in camelCase for JS/TS configs, "
      .. "kebab-case for tool configs. No trailing commas in JSON (allowed in JSONC).",
  },

  plugins = {
    {
      "b0o/schemastore.nvim",
      lazy = true,
    },
  },
}

return M
```
