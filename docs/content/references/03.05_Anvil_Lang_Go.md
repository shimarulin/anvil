# Anvil — Lang: Go

Go language pack with formatter chain and delve debugging.

## Summary

| Feature | Tool |
|---|---|
| LSP | `gopls` |
| Treesitter | `go`, `gomod`, `gosum`, `gowork` |
| Formatter | `goimports` → `gofumpt` (chain) |
| Linter | `golangci-lint` |
| DAP | `delve` |
| Test | `neotest-golang` |

## Design Decisions

- **gopls** — the official Go LSP server. Configured with semantic tokens, inlay hints, and analysis passes.
- **Formatter chain** (ADR-006) — `goimports` runs first (manages imports), then `gofumpt` (stricter formatting than gofmt).
- **golangci-lint** — meta-linter that runs multiple Go linters. Configured via `.golangci.yml` in the project root.
- **delve** — the standard Go debugger. Supports goroutine debugging.
- **neotest-golang** — better test discovery than neotest-go, supports testify and table-driven tests (ADR-017).
