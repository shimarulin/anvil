# Anvil — Language Engine

The language engine is the heart of Anvil's "language-first" philosophy. It scans, registers, and aggregates language packs — single-file Lua modules that declaratively describe everything a language needs: LSP, treesitter, formatter, linter, DAP, test runner, tasks, AI context, keymaps, and extra plugins.

## Architecture

```text
lua/anvil/lang/
├── init.lua          # Registry + aggregation engine
├── _template.lua     # Language pack contract (type definitions)
├── rust.lua          # Rust pack
├── go.lua            # Go pack
├── python.lua        # Python pack
├── typescript.lua    # TypeScript pack
├── lua.lua           # Lua pack
├── c.lua             # C/C++ pack
├── bash.lua          # Bash pack
├── json.lua          # JSON pack
├── markdown.lua      # Markdown pack
├── docker.lua        # Docker pack
├── html.lua          # HTML/CSS pack
├── sql.lua           # SQL pack
├── zig.lua           # Zig pack
├── nix.lua           # Nix pack
├── proto.lua         # Protobuf pack
└── terraform.lua     # Terraform pack
```

## How It Works

```text
┌─────────────────────────────────────────────────────────────┐
│                    LANGUAGE ENGINE                           │
│                                                             │
│  1. lang.setup(enabled_list)                                │
│     ├── Scan lua/anvil/lang/*.lua                           │
│     ├── Skip init.lua and _template.lua                     │
│     ├── require() each file → get AnvilLangPack table       │
│     ├── Filter by enabled_list (nil = all)                  │
│     └── Store in registry                                   │
│                                                             │
│  2. Aggregation functions (called by plugins/*.lua)         │
│     ├── treesitter_ensure_installed() → string[]            │
│     ├── lsp_servers() → table<server, settings>             │
│     ├── mason_ensure_installed() → string[]                 │
│     ├── formatters_by_ft() → table<ft, formatter[]>         │
│     ├── linters_by_ft() → table<ft, linter[]>               │
│     ├── dap_configurations() → table<adapter, config>       │
│     ├── neotest_adapters() → table[]                        │
│     ├── tasks() → AnvilLangTask[]                           │
│     ├── extra_plugins() → LazyPluginSpec[]                  │
│     └── ai_context() → table                                │
│                                                             │
│  3. Per-buffer functions                                    │
│     ├── current() → pack for current buffer filetype        │
│     ├── apply_keys(bufnr) → set language-specific keymaps   │
│     └── ai_context() → AI context for current language      │
└─────────────────────────────────────────────────────────────┘
```

## Dependency Rules

```text
lang/init.lua   → core/logger, core/events (optional)
lang/<name>.lua → NOTHING (pure data, no side effects)
```

Language packs are pure data tables. They never call `require()` at the top level (except for returning the table). All plugin requires happen lazily inside functions or are handled by the engine.

## Language Pack Contract

Every language pack implements the `AnvilLangPack` interface defined in `_template.lua`. The contract is strict: the engine relies on the shape of this table for all aggregation.

### Key Concepts

| Field | Required | Description |
|---|---|---|
| `name` | ✓ | Unique identifier (`"rust"`, `"python"`, etc.) |
| `filetypes` | ✓ | Vim filetypes this pack handles |
| `lsp` | ✓ | LSP server configuration |
| `treesitter` | ✓ | Treesitter parsers to install |
| `formatter` | ✓ | Formatting tool configuration |
| `linter` | — | Linting tool (nil if linting is via LSP) |
| `dap` | — | Debug adapter configuration |
| `test` | — | Test framework configuration |
| `tasks` | — | Build/run tasks for overseer |
| `ai` | — | AI context for this language |
| `keys` | — | Language-specific keybindings |
| `plugins` | — | Additional plugin specs |

### Special Flags

| Flag | Where | Purpose |
|---|---|---|
| `managed_by_plugin` | `lsp` | Skip lspconfig registration (plugin manages LSP) |
| `managed_by_lsp` | `formatter` | Skip conform registration (LSP formats) |
| `extra_servers` | `lsp` | Additional LSP servers (dual LSP, e.g. Python) |
| `chain` | `formatter` | Ordered formatter chain (e.g. Go: goimports → gofumpt) |
| `format_on_save` | `formatter` | Disable format-on-save for this language |

## Aggregation Flow

```text
plugins/lsp.lua (LazySpec)
│
├── mason-tool-installer opts:
│   └── lang.mason_ensure_installed()
│       Iterates all packs → collects:
│       - lsp.server (unless managed_by_plugin)
│       - lsp.extra_servers[].server
│       - formatter.tool
│       - formatter.chain items
│       - linter.tool
│       - dap.adapter
│
├── lspconfig config:
│   └── editor/lsp.setup()
│       └── lang.lsp_servers()
│           Iterates all packs → for each:
│           - Skip if managed_by_plugin
│           - Return { server_name = settings }
│           - Also register extra_servers
│
├── treesitter opts:
│   └── editor/treesitter.opts()
│       └── lang.treesitter_ensure_installed()
│           Iterates all packs → collects treesitter[]
│
├── conform opts:
│   └── editor/format.opts()
│       └── lang.formatters_by_ft()
│           Iterates all packs → for each filetype:
│           - Skip if managed_by_lsp
│           - Use chain if present, else { tool }
│
├── nvim-lint config:
│   └── editor/lint.setup()
│       └── lang.linters_by_ft()
│           Iterates all packs → { ft = { linter } }
│
├── nvim-dap config:
│   └── editor/dap.setup()
│       └── lang.dap_configurations()
│
├── neotest config:
│   └── editor/test.build_adapters()
│       └── lang.neotest_adapters() (adapter specs)
│
└── overseer config:
    └── workflow/tasks.register_lang_tasks()
        └── lang.tasks()
```

### `lua/anvil/lang/_template.lua`

Language pack contract — type definitions and documentation for every field.

<!-- file: lua/anvil/lang/_template.lua -->
```lua
--- Anvil language pack template / contract
--- Copy this file to lua/anvil/lang/<name>.lua and fill in.
---
--- RULES:
--- 1. This file must return a single AnvilLangPack table
--- 2. No require() calls at the top level (except returning the table)
--- 3. All plugin requires must be inside functions (lazy)
--- 4. The `name` field must match the filename (without .lua)
---
--- @class AnvilLangPack
--- @field name         string            Unique language identifier
--- @field filetypes    string[]          Vim filetypes this pack handles
--- @field lsp          AnvilLangLSP      LSP server configuration
--- @field treesitter   string[]          Treesitter parsers to install
--- @field formatter    AnvilLangFormatter Formatting configuration
--- @field linter?      AnvilLangLinter   Linting configuration (nil = via LSP)
--- @field dap?         AnvilLangDAP      Debug adapter configuration
--- @field test?        AnvilLangTest     Test framework configuration
--- @field tasks?       AnvilLangTask[]   Project tasks (build, run, etc.)
--- @field ai?          AnvilLangAI       AI context for this language
--- @field keys?        AnvilLangKey[]    Language-specific keybindings
--- @field plugins?     LazyPluginSpec[]  Additional plugins needed

--- @class AnvilLangLSP
--- @field server             string          lspconfig server name
--- @field settings?          table           LSP settings (goes into settings = {})
--- @field on_attach?         function(client, bufnr)  Extra on_attach logic
--- @field managed_by_plugin? boolean         If true, skip lspconfig registration
--- @field extra_servers?     AnvilLangExtraServer[]  Additional LSP servers

--- @class AnvilLangExtraServer
--- @field server     string                    lspconfig server name
--- @field settings?  table                     LSP settings
--- @field on_attach? function(client, bufnr)   Extra on_attach logic

--- @class AnvilLangFormatter
--- @field tool              string    Primary formatter name (for mason)
--- @field chain?            string[]  Ordered formatter chain (overrides single tool)
--- @field managed_by_lsp?   boolean   If true, skip conform registration
--- @field format_on_save?   boolean   Set to false to disable format-on-save

--- @class AnvilLangLinter
--- @field tool     string    Linter name (for mason and nvim-lint)
--- @field config?  table     Linter-specific configuration

--- @class AnvilLangDAP
--- @field adapter          string    DAP adapter name
--- @field adapter_config   table     DAP adapter definition
--- @field configurations   table[]   DAP launch configurations
--- @field filetypes?       string[]  Filetypes for these configs (defaults to pack filetypes)
--- @field dependencies?    string[]  Mason packages needed for debugging

--- @class AnvilLangTest
--- @field adapter   string    Neotest adapter module name (e.g. "neotest-rust")
--- @field config?   table     Adapter-specific configuration
--- @field keys?     AnvilLangKey[]  Test-specific keybindings

--- @class AnvilLangTask
--- @field name       string          Task display name
--- @field cmd        string|string[] Command to run
--- @field lang       string          Language name (for grouping)
--- @field filetypes  string[]        When to show this task

--- @class AnvilLangAI
--- @field system_prompt?  string    Language-specific system prompt addition
--- @field file_patterns?  string[]  Key files for project indexing
--- @field conventions?    string    Coding conventions description

--- @class AnvilLangKey
--- @field mode   string|string[]  Vim mode(s)
--- @field lhs    string           Key sequence
--- @field rhs    string|function  Action
--- @field desc   string           Description

--- EXAMPLE: Minimal language pack
--- @type AnvilLangPack
local M = {
  name = "example",
  filetypes = { "example" },

  treesitter = { "example" },

  lsp = {
    server = "example_ls",
    settings = {
      example_ls = {
        -- LSP-specific settings

    tool = "example_fmt",

  -- Optional fields below — remove if not needed

  tasks = {
    {
      name = "Example: Build",

      filetypes = { "example" },
    },

      name = "Example: Run",
```

### `lua/anvil/lang/init.lua`

Language engine — registry, scanning, and all aggregation functions.

<!-- file: lua/anvil/lang/init.lua -->
```lua
--- Anvil language engine
--- Registry, scanning, and aggregation of language packs
--- Depends on: core/logger (optional), core/events (optional)
---@class AnvilLangEngine
local M = {}

---@type table<string, AnvilLangPack>
M._registry = {}

---@type string[]
M._enabled = {}

---@type string[]
M._available = {}

---@type table<string, string>  filetype → pack name
M._ft_map = {}

--- Scan and register language packs
---@param enabled_langs? string[] list of language names to enable (nil = all)
function M.setup(enabled_langs)
  M._registry = {}
  M._enabled = {}
  M._available = {}
  M._ft_map = {}

  -- Scan lua/anvil/lang/ directory
  local lang_dir = vim.fn.stdpath("config") .. "/lua/anvil/lang"
  local files = vim.fn.glob(lang_dir .. "/*.lua", false, true)

  for _, file in ipairs(files) do
    local name = vim.fn.fnamemodify(file, ":t:r")
    -- Skip init.lua and _template.lua
    if name ~= "init" and not name:match("^_") then
      M._available[#M._available + 1] = name

      -- Check if this language is enabled
      local is_enabled = true
      if enabled_langs then
        is_enabled = vim.tbl_contains(enabled_langs, name)
      end

      if is_enabled then
        local ok, pack = pcall(require, "anvil.lang." .. name)
        if ok and type(pack) == "table" and pack.name then
          M._registry[name] = pack
          M._enabled[#M._enabled + 1] = name

          -- Build filetype → pack mapping
          if pack.filetypes then
            for _, ft in ipairs(pack.filetypes) do
              M._ft_map[ft] = name
            end
          end
        else
          local logger_ok, logger = pcall(require, "anvil.core.logger")
          if logger_ok then
            logger.warn("Lang: failed to load pack '%s': %s", name, tostring(pack))
          end
        end
      end
    end
  end

  table.sort(M._available)
  table.sort(M._enabled)

  local logger_ok, logger = pcall(require, "anvil.core.logger")
  if logger_ok then
    logger.info("Lang: %d packs enabled out of %d available", #M._enabled, #M._available)
  end

  local events_ok, events = pcall(require, "anvil.core.events")
  if events_ok then
    events.emit("lang:ready", {
      enabled = M._enabled,
      available = M._available,
    })
  end
end

--- Get a language pack by name
---@param name string
---@return AnvilLangPack?
function M.get(name)
  return M._registry[name]
end

--- Get the language pack for the current buffer's filetype
---@return AnvilLangPack?
function M.current()
  local ft = vim.bo.filetype
  local name = M._ft_map[ft]
  if name then
    return M._registry[name]
  end
  return nil
end

--- Get list of enabled language names
---@return string[]
function M.enabled()
  return vim.deepcopy(M._enabled)
end

--- Get list of all available language names
---@return string[]
function M.available()
  return vim.deepcopy(M._available)
end

-- ═══════════════════════════════════════════════════════════
-- Aggregation functions
-- ═══════════════════════════════════════════════════════════

--- Aggregate treesitter parsers from all enabled packs
---@return string[]
function M.treesitter_ensure_installed()
  local parsers = {}
  local seen = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.treesitter then
      for _, parser in ipairs(pack.treesitter) do
        if not seen[parser] then
          seen[parser] = true
          parsers[#parsers + 1] = parser
        end
      end
    end
  end
  return parsers
end

--- Aggregate LSP server configurations from all enabled packs
--- Skips servers with managed_by_plugin = true
---@return table<string, table> server_name → settings
function M.lsp_servers()
  local servers = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.lsp then
      -- Primary server
      if not pack.lsp.managed_by_plugin then
        local settings = pack.lsp.settings or {}
        local opts = { settings = settings }
        if pack.lsp.on_attach then
          opts.on_attach = pack.lsp.on_attach
        end
        servers[pack.lsp.server] = opts
      end

      -- Extra servers (e.g. ruff for Python)
      if pack.lsp.extra_servers then
        for _, extra in ipairs(pack.lsp.extra_servers) do
          local extra_opts = { settings = extra.settings or {} }
          if extra.on_attach then
            extra_opts.on_attach = extra.on_attach
          end
          servers[extra.server] = extra_opts
        end
      end
    end
  end
  return servers
end

--- Aggregate Mason tools to install from all enabled packs
---@return string[]
function M.mason_ensure_installed()
  local tools = {}
  local seen = {}

  local function add(tool)
    if tool and tool ~= "" and not seen[tool] then
      seen[tool] = true
      tools[#tools + 1] = tool
    end
  end

  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if not pack then goto continue end

    -- LSP server
    if pack.lsp then
      add(pack.lsp.server)
      if pack.lsp.extra_servers then
        for _, extra in ipairs(pack.lsp.extra_servers) do
          add(extra.server)
        end
      end
    end

    -- Formatter
    if pack.formatter then
      add(pack.formatter.tool)
      if pack.formatter.chain then
        for _, fmt in ipairs(pack.formatter.chain) do
          add(fmt)
        end
      end
    end

    -- Linter
    if pack.linter then
      add(pack.linter.tool)
    end

    -- DAP
    if pack.dap then
      if pack.dap.dependencies then
        for _, dep in ipairs(pack.dap.dependencies) do
          add(dep)
        end
      end
    end

    ::continue::
  end

  table.sort(tools)
  return tools
end

--- Aggregate formatters by filetype for conform.nvim
--- Skips formatters with managed_by_lsp = true
---@return table<string, string[]>
function M.formatters_by_ft()
  local result = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.formatter and not pack.formatter.managed_by_lsp then
      local formatters
      if pack.formatter.chain then
        formatters = vim.deepcopy(pack.formatter.chain)
      else
        formatters = { pack.formatter.tool }
      end
      for _, ft in ipairs(pack.filetypes) do
        result[ft] = formatters
      end
    end
  end
  return result
end

--- Aggregate linters by filetype for nvim-lint
---@return table<string, string[]>
function M.linters_by_ft()
  local result = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.linter then
      for _, ft in ipairs(pack.filetypes) do
        result[ft] = { pack.linter.tool }
      end
    end
  end
  return result
end

--- Aggregate DAP configurations from all enabled packs
---@return table<string, { adapter?: table, configurations?: table[], filetypes?: string[] }>
function M.dap_configurations()
  local configs = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.dap then
      configs[pack.dap.adapter] = {
        adapter = pack.dap.adapter_config,
        configurations = pack.dap.configurations,
        filetypes = pack.dap.filetypes or pack.filetypes,
      }
    end
  end
  return configs
end

--- Get neotest adapter specs (not instantiated — that happens in editor/test.lua)
---@return { adapter: string, config: table }[]
function M.neotest_adapters()
  local adapters = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.test then
      adapters[#adapters + 1] = {
        adapter = pack.test.adapter,
        config = pack.test.config or {},
      }
    end
  end
  return adapters
end

--- Aggregate tasks from all enabled packs
---@return AnvilLangTask[]
function M.tasks()
  local all_tasks = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.tasks then
      for _, task in ipairs(pack.tasks) do
        all_tasks[#all_tasks + 1] = task
      end
    end
  end
  return all_tasks
end

--- Aggregate extra plugin specs from all enabled packs
---@return LazyPluginSpec[]
function M.extra_plugins()
  local plugins = {}
  for _, name in ipairs(M._enabled) do
    local pack = M._registry[name]
    if pack and pack.plugins then
      for _, spec in ipairs(pack.plugins) do
        plugins[#plugins + 1] = spec
      end
    end
  end
  return plugins
end

--- Get AI context for the current buffer's language
---@return AnvilLangAI?
function M.ai_context()
  local pack = M.current()
  if pack and pack.ai then
    return pack.ai
  end
  return nil
end

--- Apply language-specific keymaps to a buffer
---@param bufnr number
function M.apply_keys(bufnr)
  local pack = M.current()
  if not pack or not pack.keys then
    return
  end
  for _, key in ipairs(pack.keys) do
    vim.keymap.set(key.mode, key.lhs, key.rhs, {
      buffer = bufnr,
      desc = key.desc,
    })
  end
end

--- Show info about a specific language pack
---@param name string
function M.info(name)
  local pack = M._registry[name]
  if not pack then
    vim.notify("Language pack not found: " .. name, vim.log.levels.WARN)
    return
  end

  local lines = {
    "╭─── " .. pack.name .. " ───╮",
    "│ Filetypes:  " .. table.concat(pack.filetypes, ", "),
    "│ LSP:        " .. pack.lsp.server
      .. (pack.lsp.managed_by_plugin and " (managed by plugin)" or ""),
  }

  if pack.lsp.extra_servers then
    for _, extra in ipairs(pack.lsp.extra_servers) do
      lines[#lines + 1] = "│ LSP extra:  " .. extra.server
    end
  end

  lines[#lines + 1] = "│ Treesitter: " .. table.concat(pack.treesitter, ", ")
  lines[#lines + 1] = "│ Formatter:  " .. pack.formatter.tool
    .. (pack.formatter.managed_by_lsp and " (via LSP)" or "")
    .. (pack.formatter.chain and (" [chain: " .. table.concat(pack.formatter.chain, " → ") .. "]") or "")

  if pack.linter then
    lines[#lines + 1] = "│ Linter:     " .. pack.linter.tool
  end
  if pack.dap then
    lines[#lines + 1] = "│ DAP:        " .. pack.dap.adapter
  end
  if pack.test then
    lines[#lines + 1] = "│ Test:       " .. pack.test.adapter
  end
  if pack.tasks then
    lines[#lines + 1] = "│ Tasks:      " .. #pack.tasks
  end
  if pack.ai then
    lines[#lines + 1] = "│ AI context: ✓"
  end
  if pack.keys then
    lines[#lines + 1] = "│ Keymaps:    " .. #pack.keys
  end
  if pack.plugins then
    lines[#lines + 1] = "│ Plugins:    " .. #pack.plugins
  end

  lines[#lines + 1] = "╰" .. string.rep("─", #lines[1] - 4) .. "╯"

  vim.notify(table.concat(lines, "\n"), vim.log.levels.INFO, { title = "Anvil Lang" })
end

return M
```

## Adding a New Language

```text
1. cp lua/anvil/lang/_template.lua lua/anvil/lang/elixir.lua
2. Edit elixir.lua — fill in all fields
3. Restart Neovim (or :Lazy reload)
4. Verify: :Anvil lang elixir
5. Health: :checkhealth anvil
```

The engine auto-discovers the file. No registration step needed.
