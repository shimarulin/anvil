Отлично! Давай обернём это в **функцию для `.bashrc` или `.zshrc`**, чтобы ты мог просто писать, например:

```bash
mknote "Встреча #1 с командой"
```

— и у тебя создавался бы файл с правильным именем в `context/output/`.

---

### ✅ Шаг 1: Добавь функцию в `~/.bashrc` или `~/.zshrc`

Открой терминал и выполни:

```bash
cat >> ~/.bashrc << 'EOF'

# Функция для создания .md файла с префиксом даты-времени
mknote() {
    local title="${1:-note}"
    local clean_title=$(echo "$title" | sed 's/[#:*?"<>|]/_/g; s/ /_/g; s/[^a-zA-Z0-9._-]/_/g; s/__*/_/g; s/^_*//; s/_*$//')
    local filename="context/output/$(date +'%Y-%m-%d_%H-%M-%S')_${clean_title}.md"

    touch "$filename" && echo "Файл создан: $filename"
}
EOF
```

> ⚠️ Если используешь **Zsh** (например, в macOS по умолчанию), замени `~/.bashrc` на `~/.zshrc`:

```bash
cat >> ~/.zshrc << 'EOF'
...
EOF
```

---

### ✅ Шаг 2: Перезагрузи конфиг

```bash
source ~/.bashrc
```

или, если писал в `~/.zshrc`:

```bash
source ~/.zshrc
```

---

### ✅ Теперь используй команду в любом месте:

```bash
mknote "Моя первая заметка #важно"
```

→ Создаст:
`context/output/2025-04-05_15-30-22_Моя_первая_заметка_важно.md`

```bash
mknote
```

→ Создаст:
`context/output/2025-04-05_15-30-22_note.md` (если не передано имя)

---

### 🔁 Дополнительно: Алиас (если хочешь короче)

Можешь добавить алиас, например:

```bash
alias note='mknote'
```

Тогда можно писать:

```bash
note "План на понедельник"
```

Если хочешь — могу добавить автоматическое открытие в редактор (типа `nano` или `code`).
